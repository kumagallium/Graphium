# プライバシーポリシー

**最終更新日:** 2026-11-27

Graphium はオープンソースのローカルファーストノートエディタです。このポリシーでは、アプリケーションがデータをどのように扱うかを説明します。

## Graphium について

Graphium は、プロヴェナンス（来歴）追跡機能付きのブロックベースノートエディタです。ノートはあなたのファイルシステム（デスクトップ版）またはブラウザの IndexedDB（Web 版）に保存されます。すべての編集はローカルで行われ、Graphium 自身がノートをどこかに送信することはありません。

## データ収集

**Graphium は個人データを収集・保存せず、Graphium 自身のサーバーに送ることもありません。** Graphium が動かすサーバーを通るのは、スマホ取り込みの Google の鍵だけで、それも **つないだままにする** を使っているあいだに限ります（下の「鍵の引き換え用のサーバー」を参照）。そこには何も保存しません。

- アクセス解析やトラッキングなし
- Cookie なし
- Graphium 自身のアカウント・サインインは不要
- サーバー側でのノート保存なし

## データの保存先

| データ | 保存先 |
|--------|--------|
| ノート（デスクトップ版） | あなたのファイルシステム上のプレーン JSON ファイル（既定: `~/Documents/Graphium/`、設定で変更可能） |
| ノート（Web / Docker セルフホスト） | ブラウザの IndexedDB |
| AI が使ったページ（AI チャットの回答に引用されたもの・Graphium の MCP サーバー経由で AI が開いたもの） | あなたの保存フォルダの小さなファイル（`appdata/ai-usage-*.json`）。ページの ID と時刻だけで、質問や回答は残さない。どこにも送らない |
| 個人情報 | どこにも保存しない |

デスクトップ版は、あなたのパソコンの中で小さなローカルサーバー（`127.0.0.1`。ほかのパソコンからは届きません）も動かします。アプリは起動のたびに合言葉を作ってメモリにだけ持ち、自分の要求に付けます。合言葉の無い要求は断ります。これで、ブラウザ拡張機能・Web ページ・同じパソコンのほかのユーザーは、このサーバーを使えません。あなた自身のアカウントで動くプログラムへの守りではありません（そうしたプログラムは、もともとファイルを直接読めます）。合言葉なしで動くものは 2 つです。Graphium のブラウザ拡張機能が使う Web クリップの口（専用のペアリング用の合言葉で守られます）と、画像・PDF の中継です。中継は、合言葉が無いときは公開の URL だけを取りに行き（ループバックや社内ネットワークの宛先は取りません）、手元のデータは返しません。このほかに、サーバーが動いているかを返すだけの確認用の口があり、ノートや設定は返しません。

デスクトップ版の保存先を Google Drive / iCloud / Dropbox などのクラウド同期フォルダに指定すると、OS のクラウド同期によってファイルがそのプロバイダに複製されます。Graphium 自身がノートをクラウドストレージへ送ることはありません。例外はスマホ取り込みの画面だけで、そこで自分の Google ドライブをつないだときに限り、スマホの待ち行列から送ったファイルが、スマホから Google へ直接、あなたのドライブの `Graphium/Inbox` フォルダに入ります（詳しくは[マニュアル](https://kumagallium.github.io/Graphium/manual/ja/storage-and-sync#what-goes-over-the-network)の「ネットワークに出ていくもの」の節へ）。

## サードパーティサービス

Graphium には自前のストレージやサインインの仕組みはなく（下の鍵の引き換え用のサーバーは、Google の鍵を引き換えるだけで何も保存しません）、ノートを第三者のところに預けることもありません。外のサービスとの通信は次の 3 つに分かれます。それぞれ何を送るか・いつ動くか・どう止めるかは、マニュアルの[ネットワークに出ていくもの](https://kumagallium.github.io/Graphium/manual/ja/storage-and-sync#what-goes-over-the-network)にまとめています。

- **既定では何も送りません:** ノート・素材・設定は、あなたのコンピュータ（Web 版ではブラウザ）の中にとどまります。
- **あなたが選んだときだけ:** 設定した AI の接続先や外部ツール（MCP サーバー）、**証拠として固定する**、DOI からの情報取得（DOI だけを Crossref へ送ります）、世界との照合（オンのあいだだけ Wikipedia と OpenAlex。設定で Tavily などの Web 検索をつないでいるときは、その検索サービスにも主張の文の先頭 400 文字を送ります）、自分の Google ドライブへのスマホ取り込み（スマホ取り込みの画面を開くと、つなぐ前でも Google のサインイン用スクリプトを読み込みます。この時点であなたのデータは何も送りません）。**つないだままにする** がオンのあいだは、Google の鍵が下の鍵の引き換え用のサーバーも通ります。
- **自動で出る通信（デスクトップ版）:** 更新の確認（GitHub Pages。うまくいかないときは GitHub Releases。ノートやアカウントの情報は送らず、設定でオフにできます）と、端末内の検索モデルを Hugging Face から取得する最初の 1 回（モデルのファイルを求めるだけで、あなたの文章は送りません）。

AI 機能（オプション、オプトイン）を有効にするために LLM プロバイダを設定した場合、プロンプトはそのプロバイダの規約に従って送信されます。Graphium はこの通信を中継・記録しません。macOS デスクトップ版では、入力された API キーはファイルではなく macOS の Keychain に保存されます。Keychain 保存に対応したバージョンを初めて起動した際に、それまで `models.json` に平文で保存されていた API キーは自動的に Keychain へ移行され、ファイルからは削除されます。

外部ツール（MCP サーバー）をつないだ場合、Graphium がそのサーバーと通信するのは、接続テストのときと、AI チャットが道具の一覧を取ったり道具を使ったりするときで、送るのはそれぞれの呼び出しに要る内容です。設定の **公式の一覧から探す** で検索すると、検索語（それ以外は送りません）が Graphium のバックエンドを通して MCP の公式レジストリ（`registry.modelcontextprotocol.io`）に送られます。キーを確かめる口のある接続先（Tavily）をつなぐときは、保存の前にキーを一度だけその接続先自身の API（`api.tavily.com/usage`）に送って確かめます。

履歴に残した時点で **証拠として固定する** を押したときだけ、その内容から計算した値（SHA-256 のハッシュ、32 バイト）を、Graphium のバックエンドを通して時刻証明サービス（FreeTSA と、OpenTimestamps の公開カレンダー）へ送ります。本文や素材は送りません。OpenTimestamps のカレンダーには、そのハッシュに乱数を混ぜてから計算し直した値を送るので、FreeTSA に送った値とは突き合わせられません。FreeTSA は利用ポリシー（https://freetsa.org/freetsa.html）で、証明したハッシュは保存せず、濫用の検出と調査のために送信元の IP アドレスだけを記録すると定めています。要求の User-Agent には、Graphium とその版を名乗ります。サービスには、通信元の IP アドレス・時刻・User-Agent が見えます。そのあと、証明を確定させて確かめるために、カレンダーへ確定したかを問い合わせ、Bitcoin のブロック情報（`blockstream.info`、`mempool.space`）を取得します。ボタンを押すまでは何も送らず、バックエンドの無い Web 版では何も送りません。

## 鍵の引き換え用のサーバー（スマホ取り込みの **つないだままにする**）

スマホ取り込みの画面で Google ドライブをつなぐとき、新しくつなぐ人は **つないだままにする** が既定でオンです。1 時間ごとにサインインし直さなくても、スマホがつながったままになります。これには、Graphium が動かす小さなサーバー（token broker。Cloudflare Workers 上で動き、コードは `workers/token-broker/` で公開しています）を使います。

- **しくみ:** 初めて接続するとき、Google から受け取った 1 回きりの引き換え用のコードを token broker に送ります。broker が Graphium の client secret を足して Google とコードを引き換え、アクセスの鍵（access token）と更新の鍵（refresh token）をスマホに返します。以後、アクセスの鍵が切れたら、スマホが更新の鍵を broker に送り、新しいアクセスの鍵を受け取ります。
- **通るもの:** 引き換え用のコード、アクセスの鍵、更新の鍵。
- **通らないもの:** 送るファイル（写真・メモ・URL など。スマホから Google ドライブへ直接届きます）、ノート、メールアドレスや名前。Graphium が求める範囲は `drive.file` だけです。
- **何も保存せず、ログも残しません。** broker の宛先は Google の token endpoint に固定で、ほかの Web サイトがあなたのブラウザからこのサーバーを呼ぶことはできません。ホスティング事業者の Cloudflare には、要求ごとの通信元の IP アドレス・時刻・User-Agent が見えます。また、要求が来る回数を制限するために、送信元の IP アドレスごとに数えています（Graphium のコードが IP アドレスを保存・記録することはありません）。
- **更新の鍵の置き場所:** スマホのブラウザの保存領域（`localStorage`）です。スマホの設定シートの **切断** で、Google に取り消しを送り、スマホからも消します。Google アカウントの「サードパーティのアクセス」からも取り消せます。更新の鍵そのものを手に入れた人は、broker を通して新しいアクセスの鍵を受け取れます。スマホを手放すときやなくしたときは、**切断** を押すか、Google アカウントの側で取り消してください。
- **鍵で届く範囲:** この方式で作ったファイル（`Graphium/Inbox` に送ったもの）だけで、ドライブのほかのファイルには届きません。この方式は、従来の 1 時間方式とは別の Google の client を使います。被害の範囲を、この方式で送ったファイルに限るためです。
- **オフにするには:** スマホの設定シートで **つないだままにする** をオフにします。すると Google のブラウザ用サインインを使う従来の方式になり、鍵は約 1 時間で切れて、Graphium のサーバーも通りません。自分の Google client ID を設定している場合は、従来の方式のままです。
- **以前から使っている人:** 自動で判断できるのは、このスマホに以前の接続の記録が残っている場合だけで、その場合は自分でオンにするまで変わりません。以前に **切断** して記録が残っていない場合は、次につないだときに **つないだままにする** になります。どちらの場合も、ドライブに新しい `Graphium` フォルダができます。`Graphium` フォルダが 2 つ見えたら、デスクトップの受信箱のフォルダを新しいほうに選び直します（または **つないだままにする** をオフにしてつなぎ直します）。
- **止まるとき:** サーバーに保証はなく、予告なく止まることがあります。つながらないあいだ、送るものはスマホの待ち行列に残ります。
- **Google が更新の鍵を無効にしたとき**（自分で取り消した、約 6 か月使わなかったなど）は、もう一度接続します。

## 子どものプライバシー

Graphium は 13 歳未満の子どもから意図的に情報を収集することはありません。
