# プライバシーポリシー

**最終更新日:** 2026-11-08

Graphium はオープンソースのローカルファーストノートエディタです。このポリシーでは、アプリケーションがデータをどのように扱うかを説明します。

## Graphium について

Graphium は、プロヴェナンス（来歴）追跡機能付きのブロックベースノートエディタです。ノートはあなたのファイルシステム（デスクトップ版）またはブラウザの IndexedDB（Web 版）に保存されます。すべての編集はローカルで行われ、Graphium 自身がノートをどこかに送信することはありません。

## データ収集

**Graphium は個人データを一切収集・保存・送信しません。**

- アクセス解析やトラッキングなし
- Cookie なし
- アカウント・サインイン不要
- サーバー側でのノート保存なし

## データの保存先

| データ | 保存先 |
|--------|--------|
| ノート（デスクトップ版） | あなたのファイルシステム上のプレーン JSON ファイル（既定: `~/Documents/Graphium/`、設定で変更可能） |
| ノート（Web / Docker セルフホスト） | ブラウザの IndexedDB |
| AI が使ったページ（AI チャットの回答に引用されたもの・Graphium の MCP サーバー経由で AI が開いたもの） | あなたの保存フォルダの小さなファイル（`appdata/ai-usage-*.json`）。ページの ID と時刻だけで、質問や回答は残さない。どこにも送らない |
| 個人情報 | どこにも保存しない |

デスクトップ版の保存先を Google Drive / iCloud / Dropbox などのクラウド同期フォルダに指定すると、OS のクラウド同期によってファイルがそのプロバイダに複製されます。Graphium 自身がクラウドストレージ API と通信することはありません。

## サードパーティサービス

Graphium はストレージや認証に関してサードパーティサービスを利用していません。

AI 機能（オプション、オプトイン）を有効にするために LLM プロバイダを設定した場合、プロンプトはそのプロバイダの規約に従って送信されます。Graphium はこの通信を中継・記録しません。macOS デスクトップ版では、入力された API キーはファイルではなく macOS の Keychain に保存されます。Keychain 保存に対応したバージョンを初めて起動した際に、それまで `models.json` に平文で保存されていた API キーは自動的に Keychain へ移行され、ファイルからは削除されます。

外部ツール（MCP サーバー）をつないだ場合、Graphium がそのサーバーと通信するのは、接続テストのときと、AI チャットが道具の一覧を取ったり道具を使ったりするときで、送るのはそれぞれの呼び出しに要る内容です。設定の **公式の一覧から探す** で検索すると、検索語（それ以外は送りません）が Graphium のバックエンドを通して MCP の公式レジストリ（`registry.modelcontextprotocol.io`）に送られます。キーを確かめる口のある接続先（Tavily）をつなぐときは、保存の前にキーを一度だけその接続先自身の API（`api.tavily.com/usage`）に送って確かめます。

履歴に残した時点で **証拠として固定する** を押したときだけ、その内容から計算した値（SHA-256 のハッシュ、32 バイト）を、Graphium のバックエンドを通して時刻証明サービス（FreeTSA と、OpenTimestamps の公開カレンダー）へ送ります。本文や素材は送りません。OpenTimestamps のカレンダーには、そのハッシュに乱数を混ぜてから計算し直した値を送るので、FreeTSA に送った値とは突き合わせられません。FreeTSA は利用ポリシー（https://freetsa.org/freetsa.html）で、証明したハッシュは保存せず、濫用の検出と調査のために送信元の IP アドレスだけを記録すると定めています。要求の User-Agent には、Graphium とその版を名乗ります。サービスには、通信元の IP アドレス・時刻・User-Agent が見えます。そのあと、証明を確定させて確かめるために、カレンダーへ確定したかを問い合わせ、Bitcoin のブロック情報（`blockstream.info`、`mempool.space`）を取得します。ボタンを押すまでは何も送らず、バックエンドの無い Web 版では何も送りません。

## 子どものプライバシー

Graphium は 13 歳未満の子どもから意図的に情報を収集することはありません。
