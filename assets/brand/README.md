# Graphium brand assets

The two transparent PNG files in this directory are the single source for the
Graphium mark and wordmark. They were faithfully extracted from the approved
design using the built-in `image_gen` tool. The wordmark retains its original
letter shapes; no installed font is required.

The compact in-app lockup uses the generated PNGs as alpha masks, with a 24 px
mark and an 18 px wordmark. Both use the theme's muted foreground color, preserving
the approved shapes while matching the surrounding interface.

Run from the repository root after `pnpm install` (Playwright Chromium must be
installed):

```sh
pnpm brand:generate
```

The script trims transparent margins, preserves the source alpha contours,
normalizes the mark to green `#286149` and the wordmark to charcoal `#27332F`, and
resizes or converts formats. It does not redraw the design. The social card uses
background `#FAFAF7`; reversed marks use white. Tauri CLI output is temporary,
and only the five existing desktop icon files are copied into the repository.
Alpha values of 1/255 scattered around the source are ignored only when finding
the crop bounds; alpha inside the crop is preserved. Visible black backgrounds
are rejected (the source has no black pixels with alpha of 16/255 or higher).

| `manual/public/{logo,logo-light,apple-touch-icon}.png`, `favicon.ico` | Copies for the manual |
| `extensions/chrome/icons/icon-*.png` | Small rounded tile icons at 16, 32, 48, and 128 px |
| `src-tauri/icons/*` | Five desktop PNG, ICO, and ICNS assets generated by Tauri |

For future changes, update the approved source PNGs here and rerun the script.
Do not edit individual generated assets.

Refresh the Chrome Web Store artwork and prepare its separately versioned package:

```sh
node scripts/chrome-web-store-assets.mjs
pnpm ext:pack
```

The Graphium desktop release does not publish the extension to the Chrome Web
Store. Submit the resulting package through the extension's store dashboard.

## Extraction prompt

Use the approved design as the sole reference. Faithfully extract only the
Graphium G mark (or, for the other source, only the Graphium wordmark). Preserve
every contour, proportion, stroke, node, and letter shape exactly. Remove all
background and surrounding elements. Return a clean transparent PNG with true
alpha, without a black or white background, shadows, added effects, or redesign.
