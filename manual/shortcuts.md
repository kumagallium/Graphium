# Keyboard shortcuts

Graphium keeps its shortcut list short on purpose: a handful of keys for capturing, saving, and labeling, so your hands stay on the keyboard while you write. This page lists every shortcut, when each one is active, and where the app itself reminds you of them.

A note on notation: `⌘` is the mac Command key, `⇧` is Shift, and `⌥` is Option. On Windows and Linux, `⌘` becomes `Ctrl` and `⌥` becomes `Alt` — every shortcut below is listed in both forms.

## General

| mac | Windows / Linux | What it does |
|---|---|---|
| `⌘K` | `Ctrl+K` | Opens the Composer — a single box to find a note or ask AI. Works from any screen; where no note is being edited it opens in search-only form. Needs an AI model set up in [Settings](/settings). See [AI chat and Ask](/ai-chat-and-ask). |
| `⌘⇧M` | `Ctrl+Shift+M` | Opens the quick memo dialog from anywhere in the app — note editor, note list, any screen. Memos are the raw material you capture now and use later. |
| `⌘D` | `Ctrl+D` | Duplicates the block the cursor is in, directly below it. Works inside the editor only — see [Duplicating a block](/notes-and-editor#duplicating-a-block). |
| `⌘F` | `Ctrl+F` | Opens **Find in note** — search within the current note with highlighted matches. When no note is open, the browser's own find works as usual. |
| `⌘\` | `Ctrl+\` | Collapses or expands the sidebar for distraction-free writing. Desktop-size screens only — small screens have no permanent sidebar to collapse. On JIS keyboards, the `¥` key works too. |
| `Esc` | `Esc` | Closes the Composer, the in-note search bar, the quick memo dialog, and most other dialogs. |

## Saving

| mac | Windows / Linux | What it does |
|---|---|---|
| `⌘S` | `Ctrl+S` | Saves the current note immediately. Graphium also autosaves, so this is for peace of mind before you step away. Works in the main editor and in the side peek. |
| `⌘⇧S` | `Ctrl+Shift+S` | Saves a version — a named snapshot you can revisit, compare, and fork from the **History** panel. |
| `⌘⌥S` | `Ctrl+Alt+S` | Same as above. A fallback for when your OS, browser, or an extension reserves `⌘⇧S` and the keystroke never reaches Graphium. |

Versions are for your own notes: knowledge pages generated by AI don't take snapshots. If neither snapshot shortcut works in your environment, the **Save version** item in the note's `⋯` menu does the same thing.

## Labels

These four shortcuts apply an inline label to the text you have selected. They work inside the body of a step block — the part of your note that becomes a step in the [provenance graph](/labels-and-provenance). Pressing the same shortcut on already-labeled text removes the label.

| mac | Windows / Linux | Label |
|---|---|---|
| `⌘⇧I` | `Ctrl+Shift+I` | **Input** — a material or ingredient the step uses |
| `⌘⇧E` | `Ctrl+Shift+E` | **Tool** — the instrument or software used (*E* as in *Equipment* — `⌘⇧T` is reserved by browsers for reopening closed tabs) |
| `⌘⇧P` | `Ctrl+Shift+P` | **Parameter** — a setting or condition |
| `⌘⇧O` | `Ctrl+Shift+O` | **Output** — what the step produces |

A few boundaries, all deliberate:

- Labels can only be *added* inside a step's body — not in the step title (that names the activity itself) and not inside table cells (tables are interpreted structurally instead). *Removing* an existing label works anywhere.
- The same four buttons appear in the floating toolbar whenever you select text, so the shortcuts are optional.

## Confirming

| mac | Windows / Linux | What it does |
|---|---|---|
| `⌘Enter` | `Ctrl+Enter` | Sends or confirms in multi-line inputs where plain `Enter` inserts a line break: the AI chat, the Composer, the citation pickers, the quick memo dialog, and forms in [Settings](/settings) (for example, adding an MCP server). |

## Typing triggers

Two characters act as menus while you write. They aren't modifier shortcuts, but they belong in the same muscle memory:

| Type | Where | What it does |
|---|---|---|
| `/` | On an empty line | Opens the slash menu — blocks (steps, tables, formulas, callouts…), media, citations, and templates. See [Notes & editor](/notes-and-editor). |
| `@` | Anywhere inline | Opens a search menu to link another note, a material, or a knowledge page — or create a new note on the spot. |

An empty note shows a small guide card with exactly these three entry points — **Ask AI** (`⌘K`), **Link a note** (`@`), and **Slash menu** (`/`) — so your first note teaches you the essentials.

## Good to know

**Label shortcuts follow key positions, not characters.** `⌘⇧I` and friends are detected by the physical key position, so they work identically on US, JIS, and other keyboard layouts — no matter what character the key prints.

**There is deliberately no shortcut for a new note.** `⌘⇧N` is reserved by browsers for a new private window and can't be reliably overridden, so a shortcut there would misfire for some users. Use the **+ Note** button in the sidebar instead. Memos get a shortcut and notes don't, and that asymmetry is intentional: memos are for instant capture, notes are where you sit down and write.

**The app reminds you as you go.** You don't need to memorize this page — the shortcuts appear right where you'd use them:

- The floating toolbar's label buttons show keycap hints (`⌘` `⇧` `I`) and tooltips.
- The sidebar's **+ Memo** button tooltip reads **Capture a quick memo (⌘+⇧+M)**, and the sidebar toggle reads **Collapse sidebar (⌘+\\)**.
- The note's `⋯` menu shows the snapshot shortcut next to **Save version**.
- The Composer's footer shows `⌘Enter` **to send** and `Esc` **to close**, and the quick memo dialog says **Press ⌘+Enter to save**.
