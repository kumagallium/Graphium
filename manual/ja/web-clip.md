# Web クリップ <Badge type="tip" text="v0.112.0 (2026-11-04) で追加" />

一日に目を通すもののかなりの部分は、ブラウザで読んでいます。HTML 版の論文、記事、ドキュメントなどです。Web クリップを使うと、ページを離れずに、大事な文だけを Graphium に残せます。

Chrome の拡張機能が、選んだ文をデスクトップ版の Graphium に送ります。1 回のクリップは、次の 2 か所に入ります。

- **メモとして**: 選んだ文が、そのページを出典としたメモになります。ほかのメモと同じように一覧に並ぶので、あとから別のノートに引用できます。
- **そのページのノートの引用として**: ページごとに 1 つのノートが、**Web clips** フォルダにできます。表示言語にかかわらず、フォルダ名は **Web clips** です。最初のクリップで、ページへのブックマークと引用の入ったノートができます。同じページからの 2 回目以降のクリップは、同じノートの末尾に追加されます。

![Web クリップのノート。ページの題、Web clips フォルダのチップ、ページへのブックマーク、クリップした 3 つの文の引用](/screenshots/web-clip-note.png)

Web クリップは、[デスクトップ版](/ja/desktop-app)とセルフホストのサーバーで使えます。拡張機能が連絡を取るのは、このコンピューターの Graphium だけです。

## 準備

1. **拡張機能を入れる。** [Chrome ウェブストアの Graphium Web クリップ](https://chromewebstore.google.com/detail/hncdmkjjpdjjdfdclkdpjmoomlmfdljj)を開き、**Chrome に追加** を押します。アイコンをいつも表示しておくには、ツールバーのパズルの形（拡張機能）のメニューから、アイコンを固定します。
2. **Graphium とつなぐ。** Graphium を起動しておきます。ツールバーの拡張機能のアイコンを押すと、まだつながっていないので、設定が開きます。**Graphium とつなぐ** を押すと、4 桁の番号が出ます。

   ![拡張機能の設定画面。「Graphium とつなぐ」を押した後で、4 桁の番号と案内が出ている](/screenshots/web-clip-extension.png)

3. **Graphium で許可する。** Graphium に **ブラウザの拡張機能をつなぎますか？** と表示されます。拡張機能に出ている番号と同じかどうかを見比べて、**許可する** を押します。拡張機能の画面が **つなぎました。** に変われば完了です。

   ![Graphium の確認。拡張機能と同じ 4 桁の番号と、許可しない・許可する](/screenshots/web-clip-pair.png)

この準備は 1 回だけです。つないだ状態は拡張機能に保存されます。

**コードを貼ってつなぐこともできます。** 古い版の Graphium やセルフホストのサーバーなどで、ボタンではつながらないときに使います。

1. Graphium の **設定 → ストレージ** で **スマホやブラウザから送る** を開きます。
2. **Web クリップ** のペアリングコードを **コピー** します。
3. 拡張機能の設定の **詳しい設定** に貼り付けて、**保存** します。

![設定の Web クリップ。ペアリングコード（最初は伏せてある）と、コピー・コードを作り直す](/screenshots/web-clip-settings.png)

## クリップする

| やりたいこと | 操作 |
|---|---|
| 文や段落を残す | 選んで、ツールバーの Graphium のアイコンを押す |
| キーボードで同じことをする | 選んで `⌥⇧C`（Windows/Linux は `Ctrl+Shift+Y`）。キーは `chrome://extensions/shortcuts` で変えられます |
| 右クリックで同じことをする | 選んで右クリック →「**Graphium にクリップ**」 |
| 引用なしでページだけ残す | 何も選ばずにアイコン（またはキー）を押すか、ページの上で右クリック →「**このページを Graphium にクリップ**」。ブックマークだけのノートができます |

**ブラウザで開いた PDF では、右クリックを使います。** PDF の中で選んだ文は、右クリックの「**Graphium にクリップ**」でクリップできます。アイコンとキーでは、選んだ文を読み取れません。そのため、ページだけが残ります。

拡張機能の設定は、ツールバーのアイコンを右クリック →「**オプション**」で開きます。

クリップすると、ツールバーのアイコンに短い印が出ます。

- **✓**: Graphium に届きました。
- **…**: Graphium が起動していないので、あとで送るために取っておきました。
- **!**: うまくいきませんでした。アイコンにマウスを載せると、理由が出ます。

**「同じページ」とみなす範囲。** 次の場合は、同じノートに入ります。

- アドレスの違いが、`#見出し` の部分や `utm_source` などの追跡用パラメータだけのとき。
- DOI を持つ論文のページで、同じ論文の別のアドレス（出版社のページとミラーなど）からクリップしたとき。

**ノートを開いているとき。** そのページのノートを Graphium で開いている間にクリップすると、引用がすぐにノートに入ります。保存は、いつもどおり行われます。

**Graphium が閉じているとき。** 拡張機能が、クリップを最大 200 件まで取っておきます。取っておいたクリップは、次のどれかのときに送られます。

- 次にクリップしたとき
- Chrome を起動したとき
- 拡張機能の設定画面で **今すぐ送る** を押したとき

## どこに何が入るか

| 場所 | 中身 |
|---|---|
| メモ | クリップ 1 回につき 1 件。本文は、選んだ文の後ろに `— <ページの題>` が付く。日時はクリップした時刻で、出典はそのページ |
| 素材 → URL | そのページが 1 件。同じページからのクリップは、これを共有する |
| ノート → Web clips | ページごとに 1 つ。題を変えても、別のフォルダに移しても、引用の間に自分の考えを書き足しても構わない。後のクリップは末尾に追加される |

ページのノートを削除する（ゴミ箱に移す）と、そのページからの次のクリップで新しいノートができます。

## プライバシーとセキュリティ

- 拡張機能がクリップを送る先は、`127.0.0.1`（このコンピューターの Graphium）だけです。利用状況の計測はしません。ほかのサーバーには何も送りません。
- ページを読むのは、クリップした瞬間の、クリップしたタブだけです。裏で、開いているすべてのページを読むことはありません。
- 拡張機能が求める権限は、**activeTab**・**contextMenus**・**scripting**・**storage** と、`http://127.0.0.1` へのアクセスだけです。
- つなぐと、拡張機能は、あなたの Graphium にクリップを送るためのコード（ペアリングコード）を受け取ります。開いている Web ページはこのコードを持たないので、クリップを送れません。このコードでノートを読むこともできません。
- つなぐ申し込みを受け付けるのは、Chrome の拡張機能からだけです。Web ページからは申し込めません。ほかの拡張機能が申し込んできても、あなたが許可しなければつながりません。番号が違うとき、または自分で **Graphium とつなぐ** を押していないときは、**許可しない** を選んでください。
- コードは、パスワードと同じように扱ってください。漏れたときは、設定の **コードを作り直す** を押して、拡張機能でもう一度つなぎます。
- クリップした文は、平文（暗号化されていない状態）で保存されます。そのノートに[AI の機能](/ja/ai-chat-and-ask)を使うと、ほかのノートと同じように、あなたが設定した AI の接続先へ送られます。
