# Web クリップ <Badge type="tip" text="v0.112.0 (2026-11-04) で追加" />

一日に目を通すもののかなりの部分は、ブラウザで読んでいます。HTML 版の論文、記事、ドキュメントなどです。Web クリップを使うと、ページを離れずに大事な文だけを Graphium に残せます。Chrome の拡張機能が、選んだ文をデスクトップ版の Graphium に送ります。1 回のクリップは 2 か所に入ります。

- **メモとして** — 選んだ文が、ページを出典としたメモになります。ほかのメモと同じく一覧に並ぶので、あとから別のノートに引用できます。
- **そのページのノートの引用として** — ページごとに 1 つのノートが **Web clips** フォルダにできます（表示言語に関わらずこの名前です）。最初のクリップでノート（ページへのブックマークと引用）ができ、同じページからの 2 回目以降のクリップは同じノートの末尾に追加されます。

![Web クリップのノート。ページの題、Web clips フォルダのチップ、ページへのブックマーク、クリップした 3 つの文の引用](/screenshots/web-clip-note.png)

Web クリップは[デスクトップ版](/ja/desktop-app)（とセルフホストのサーバー）で使えます。拡張機能がやり取りするのは、このコンピューターの Graphium だけです。

## 準備

1. **拡張機能を入れる。** まだ Chrome ウェブストアには出していません。[Graphium のリポジトリ](https://github.com/kumagallium/Graphium)を（Code → Download ZIP で）ダウンロードして展開します。Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにして、**パッケージ化されていない拡張機能を読み込む** から `extensions/chrome` フォルダを選びます。
2. **Graphium とつなぐ。** Graphium を起動しておきます。ツールバーの拡張機能のアイコンを押すと、まだつながっていないので設定が開きます。**Graphium とつなぐ** を押すと、4 桁の番号が出ます。

   ![拡張機能の設定画面。「Graphium とつなぐ」を押した後で、4 桁の番号と案内が出ている](/screenshots/web-clip-extension.png)

3. **Graphium で許可する。** Graphium に **ブラウザの拡張機能をつなぎますか？** と出ます。拡張機能に出ている番号と同じか見比べて、**許可する** を押します。拡張機能の画面が **つなぎました。** に変われば完了です。

   ![Graphium の確認。拡張機能と同じ 4 桁の番号と、許可しない・許可する](/screenshots/web-clip-pair.png)

この準備は 1 回だけです。つないだ状態は拡張機能に保存されます。

**コードを貼ってつなぐこともできます。** ボタンでつながらないとき（古い版の Graphium やセルフホストのサーバーなど）は、Graphium の **設定 → ストレージ** で **スマホやブラウザから送る** を開き、**Web クリップ** のペアリングコードを **コピー** します。拡張機能の設定の **詳しい設定** に貼って **保存** します。

![設定の Web クリップ。ペアリングコード（最初は伏せてある）と、コピー・コードを作り直す](/screenshots/web-clip-settings.png)

## クリップする

| やりたいこと | 操作 |
|---|---|
| 文や段落を残す | 選んで、ツールバーの Graphium のアイコンを押す |
| キーボードで同じことをする | 選んで `⌥⇧C`（Windows/Linux は `Ctrl+Shift+Y`）。キーは `chrome://extensions/shortcuts` で変えられます |
| 右クリックで同じことをする | 選んで右クリック →「**Graphium にクリップ**」 |
| 引用なしでページだけ残す | 何も選ばずにアイコン（またはキー）を押すか、ページの上で右クリック →「**このページを Graphium にクリップ**」。ブックマークだけのノートができます |

**ブラウザで開いた PDF では右クリックを使います。** PDF の中で選んだ文は、右クリックの「**Graphium にクリップ**」でクリップできます。アイコンとキーでは選んだ文を読めないので、ページだけが残ります。

拡張機能の設定は、ツールバーのアイコンを右クリック →「**オプション**」で開きます。

ツールバーのアイコンに短い印が出ます。**✓** は Graphium に届いたとき、**…** は Graphium が起動しておらず後で送るために取っておいたとき、**!** はうまくいかなかったときです（アイコンにマウスを載せると理由が出ます）。

**「同じページ」とみなす範囲。** アドレスの違いが `#見出し` の部分や `utm_source` などの追跡用パラメータだけなら、同じノートに入ります。DOI を持つ論文のページなら、同じ論文の別のアドレス（出版社のページとミラーなど）からのクリップも同じノートに入ります。

**ノートを開いているとき。** そのページのノートを Graphium で開いている間にクリップすると、引用がすぐにノートに入り、いつもどおり保存されます。

**Graphium が閉じているとき。** 拡張機能が最大 200 件を取っておき、次にクリップしたとき・Chrome を起動したとき・拡張機能の設定画面で **今すぐ送る** を押したときに送ります。

## どこに何が入るか

| 場所 | 中身 |
|---|---|
| メモ | クリップ 1 回につき 1 件。本文は選んだ文の後ろに `— <ページの題>`。日時はクリップした時刻、出典はそのページです |
| 素材 → URL | そのページが 1 件。同じページからのクリップはこれを共有します |
| ノート → Web clips | ページごとに 1 つ。題を変えても、別のフォルダに移しても、引用の間に自分の考えを書き足しても構いません。後のクリップは末尾に追加されます |

ページのノートを削除する（ゴミ箱に移す）と、そのページからの次のクリップで新しいノートができます。

## プライバシーとセキュリティ

- 拡張機能がクリップを送る先は `127.0.0.1`（このコンピューターの Graphium）だけです。計測は無く、ほかのサーバーには何も送りません。
- ページを読むのはクリップした瞬間だけ、クリップしたタブだけです。裏ですべてのページを読むことはしません。
- 求める権限は **activeTab**・**contextMenus**・**scripting**・**storage** と `http://127.0.0.1` へのアクセスだけです。
- つなぐと、拡張機能はあなたの Graphium にクリップを送るためのコード（ペアリングコード）を受け取ります。開いている Web ページはこのコードを持たないので、クリップを送れません。コードでノートを読むこともできません。
- つなぐ申し込みは、Chrome の拡張機能からしか受け付けません。Web ページからは申し込めません。ほかの拡張機能が申し込んできても、あなたが許可しなければつながりません。番号が違うとき、自分で **Graphium とつなぐ** を押していないときは **許可しない** を選んでください。
- コードはパスワードと同じように扱います。漏れたら設定の **コードを作り直す** を押して、拡張機能でもう一度つないでください。
- クリップした文は平文で保存されます。あとでこれらのノートに [AI の機能](/ja/ai-chat-and-ask)を使うと、ほかのノートと同じように、あなたの AI の接続先へ送られます。
