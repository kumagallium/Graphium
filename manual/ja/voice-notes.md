# 音声ノート <Badge type="tip" text="v0.91.0 (2026-10-20) で追加" /> {#voice-notes}

会議では、誰も書き留めなかった決定がたくさん生まれます。**音声ノート**は、会議（あるいは自分の声だけ）をパソコンの中で録音し、そのまま手元で文字に起こします。要約の「決定事項」から、実際に誰かが話した一文まで、たどって確かめられます。

- **ボットは会議に入りません。** パソコンから流れる音とマイクに入る音を録るので、Zoom・Teams・Gather・ブラウザのタブのどれでも同じように使えます。
- **音声はパソコンの外に出ません。** 録音も文字起こしも手元で動きます。通信するのは、音声モデルを最初に取得するときだけです。数値の裏付けは [FAQ](/ja/faq) にあります。
- **ノートの中のブロックです。** 文字起こしは、ほかのブロックと同じようにノートに並びます。前後に書き足したり、要約したり、リンクしたりできます。

::: info デスクトップ版だけ
音声ノートには[デスクトップ版](/ja/desktop-app)が要ります。ブラウザやスマホでは、ブロックに **このデバイスでは録音できません** または **このデバイスでは読めません** と出ます。ノート自体は開け、デスクトップで開き直せばブロックも元どおりに動きます。
:::

## 音声ノートを始める {#starting}

入口は 2 つです。

| 場所 | 起きること |
|---|---|
| **+ ノート ▾** → **音声ノート** | 「音声ノート …」というタイトルの新しいノートが開き、先頭に音声ノートのブロックが置かれます |
| どのノートでも `/音声`（英語なら `/audio`） | カーソルの位置にブロックを入れます（スラッシュメニューの表示は **音声（この位置に文字起こし）**） |

![+ ノート の ▾ の先のメニュー。白紙ノート・音声ノート・テンプレートから…](/screenshots/new-note-menu.png)

どちらの入口でも、置かれるのは**準備中のブロック**で、録音は始まりません。**音声ノート** の見出しと **録音を始める** ボタンが出て、このボタンを押すまで何も録りません。準備中のブロックは、ノートの中で好きなだけ待たせておけます。会議が始まったときに押してください。

## 録音する {#recording}

録音の前に、ブロックには同意についての文が出ます。

- **開始すると、参加者全員が録音と文字起こしに同意したものとして扱います。** 参加者への声かけは、あなたの役目です。Graphium は静かに録るので、先に断っておいてください。
- **相手の声も録る（オンライン会議のとき）** は、既定でオンです。オフにすると自分の声だけを録ります。そのとき、ブロックには **自分の声だけを文字にします** と出ます。考えを声に出して残すときや、対面の会話に向いています。
- **ヘッドホンを使うと、相手の声がマイクに混ざりません。** オンライン会議ではヘッドホンをおすすめします。使わないと、スピーカーの音がマイクにも入り、同じ発言が二重に文字になります。

**録音を始める** を押すと、見出しが **録音中** に変わり、経過時間が進みます。終わったら **止める** を押してください。録音は素材の **音声**（「会議 …」という `.wav`）に保存され、ブロックが残りを仕上げます。3 時間の上限に達したときや、ウィンドウを閉じたときも、自動で止めて保存します。

### 許可 {#permissions}

| 環境 | 最初の録音で求められるもの |
|---|---|
| **macOS** | 相手の声を録るための**画面収録の許可**（システム設定 → プライバシーとセキュリティ → **画面収録とシステムオーディオ録音** で Graphium を許可）と、自分の声のための**マイクの許可** |
| **Windows** | マイクの許可（Windows が尋ねたとき） |

macOS で相手の声を録るには **macOS 12.3 以降**が要ります（使っている仕組みがそこで入ったため）。macOS 11 や 12.0〜12.2 でも Graphium は動き、自分の声は録れます。始める前に **相手の声も録る** をオフにしてください。

macOS で許可がないときは、**画面収録の許可が必要です** と出て、**設定を開く** ボタンが現れます。許可したら **Graphium を再起動**してください（同じメッセージの **再起動** ボタンが使えます）。macOS は、起動し直したアプリにだけ許可を反映します。

マイクが使えないときは、相手の声だけを録り続けます。止めたときに、どちらの声が入っていないかを知らせます（例: **録音を素材に保存しました（自分の声は入っていません）**）。

## 文字起こしブロック {#transcript-block}

![完了した音声ノートのブロック。相手 / 自分のラベルが付いた文字起こしと、再生・段落に展開・要約のボタン](/screenshots/voice-note-block.png)

録音中は、約 **20 秒遅れて**ブロックに発言が並びます。音声が溜まった窓を会話の間で切って文字にし、停止後に残りを仕上げます。処理中は **文字起こし中 · N 発言** と出て、終わると **文字起こし** に落ち着きます。

- **相手 / 自分。** 各行は `[mm:ss]` の時刻と、**相手**（会議の向こう側）か **自分**（マイク）で始まります。録るときから 2 つの声を分けているので、ラベルは推測ではありません。
- **再生と時刻のクリック。** **再生** で録音を再生し、`[mm:ss]` の時刻をクリックするとその発言から再生します（**この発言の位置から再生**）。音声は最初に再生を押したときに読み込みます。再生では左右の声を中央に混ぜて流します。
- **たたむ / ひらく・すべて表示。** 長い文字起こしは直近 20 発言だけを出します。**すべて表示（ほかに N 発言）** で残りが開き、**たたむ** でブロックの本体が閉じます。
- **段落に展開。** 発言を 1 行ずつ通常の段落にして、ブロックの下に並べます。聞き違いを直したり、補足を書いたり、要約の元にしたりできます。ブロックは見出しだけに縮み（**展開済み（N 発言）**）、**原本を見る** で手を入れていない文字起こしにすぐ戻れます。
- **途中で止まったとき。** **文字起こしは途中で止まりました** は、音声モデルが最後まで終えられなかったという意味です。そこまでの分は残ります。[素材](/ja/materials-and-citations)でその録音を開き、**文字起こし** でもう一度実行できます。

発言のテキストは、ノートのファイルではなく録音の素材のそばに保存されます。長い会議でもノートが重くなりません。ノートを共有するときは、録音も一緒に渡す必要があります。

## 要約と来歴 {#summary}

発言が段落になったら、**要約** を押します。AI モデルが大事な点を拾い、ブロックのすぐ下にまとめて書き込みます。

- **決定事項**・**TODO**（会話に出ていれば **担当** と **期限** 付き）・**論点** が、短い箇条書きで並びます。
- **要約** の見出しの下に **AI がまとめました。根拠は各項目のリンクから** と 1 行入り、機械が書いた文だと分かります。
- **どの項目も、元になった段落へリンクが張られます。** AI の要約を実際の発言と見比べ、そこから音声を再生できます。

もう一度やるときは **もう一度要約** を押します。前回の要約は置き換えられます。要約を手で直していたときは、先に **前回の要約を編集しています。置き換えますか？** と確かめます。中身が空の結果で、いまの要約が消えることはありません。1,500 発言または 60,000 字を超える長い会議は、一度には要約できません。

要約には AI モデルが要ります。[AI の設定](/ja/ai-setup)で用意してください。要約は、会議の言語が混在していても、Graphium の表示言語で書かれます。文字起こし自体には、AI モデルもアカウントも要りません。

つながりは[来歴](/ja/labels-and-provenance)として残ります。**要約の項目 → 段落 → 文字起こしブロック → 文字起こし → 録音** です。[PROV-JSON-LD の書き出し](/ja/labels-and-provenance#prov-json-ld-で書き出す)で、端から端までたどれます。文字起こしの工程はシステムの工程なので、あなたが書いた手順のようにステップパネルには出ません。

## モデルと設定 {#settings}

![設定 → AI → 会議の録音と文字起こし。モデル・言語・よく使う用語・録音中に文字起こしを進める](/screenshots/voice-note-settings.png)

[設定](/ja/settings) → **AI** → **会議の録音と文字起こし** を開きます（デスクトップ版のみ）。

| 設定 | 内容 |
|---|---|
| **モデル** | **高精度・推奨（large-v3-turbo）** は 574 MB で、いちばん正確な既定のモデルです。**small**（軽め・低スペック向け、488 MB）と **base**（さらに軽め、148 MB）は、正確さと引き換えに軽く動きます。それぞれ **取得**、取得中は **取り消し**、取得後は **削除** のボタンがあります。 |
| **言語** | **自動**・**日本語**・**英語**。会議の言語が分かっているなら固定してください。自動よりも確実です。 |
| **よく使う用語（文字起こしのヒント）** | カンマ区切りで 200 文字まで。製品名・人名・専門用語などを書くと、聞き取りの手がかりになります。ノートのタイトルもヒントに使うので、音声ノートには話題に合った名前を付けておくと効きます。 |
| **録音中に文字起こしを進める** | 既定ではオンです。オフにすると会議中は発言が並ばず、止めたあとに録音の素材のプレビューから **文字起こし** を実行します。 |

モデルは、最初に必要になったときに一度だけ取得し、パソコンに残ります。取得するまでは **文字起こしモデルが未取得です。録音だけ行います。設定から取得できます** と出ます。録音は保存されるので、取得したあとに文字起こしできます。

## 知っておきたい限界 {#limits}

- **言語の混在。** 自動は、話の区切りごとに日本語か英語かを判定します。1 つの文の途中で言語が切り替わると、少ない側の言語の語が落ちることがあります。分かるときは、設定で言語を固定してください。
- **同音異義語と固有名詞。** 音の同じ語は文脈で選ぶので、専門用語や人名は間違えることがあります。**よく使う用語** に入れておき、残りは **段落に展開** したあとで直してください。
- **ヘッドホンなしだと、相手の声が二重になります。** 通話の音と、マイクに回り込んだ音の 2 回です。
- **分けられるのは 2 つの側だけ。** 向こう側の人は全員 **相手** です。複数の話者までは見分けません。
- **Windows は CPU で動きます。** 文字起こしが遅くなり、20 秒より遅れて並ぶことがあります。飛ばされる区間はありません。溜まった分をまとめて処理します。
- **静かな区間や無音。** 音声モデルが無音の上に文を作り出さないよう、無音は意図的に飛ばします。とても小さな声は、一緒に飛ぶことがあります。

これらは不具合ではなく意図した選択です。しきい値は [FAQ](/ja/faq) の「会議の文字起こし」の行にあります。
