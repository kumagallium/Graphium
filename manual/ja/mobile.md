# スマホでの記録

ひらめきは、机に座っているときにやってくるとは限りません。Graphium では、スマホを**思いついたことをその場で記録するための端末**として使います。メモを走り書きし、写真を撮り、リンクを保存しておく場所です。整理したり、引用したり、知識に育てたりするのは、あとでパソコンの上で行います。

スマホだけで完結するノートアプリにしていないのは、意図したことです。考えるのはデスクトップで、スマホはそこへ材料を送る役です。

## デスクトップでのクイックメモ

いちばん速い記録に、スマホは要りません。Graphium のどこでも `⌘⇧M`（Windows / Linux は `Ctrl+Shift+M`）を押すと、クイックメモのダイアログが開きます。思いついたことを打ち込み、`⌘Enter` で保存してください。書いていたノートには触れず、メモのコレクションに入ります。

![クイックメモのダイアログ](/screenshots/quick-memo.png)

### メモは「いま見ているもの」に付く <Badge type="tip" text="v0.109.0 (2026-10-30) で追加" />

メモは、`⌘⇧M` を押したときにどこを見ていたかを覚えています。あとで、そこへ戻る手がかりになります。

| いま見ているもの | メモの付け先 |
|---|---|
| 素材の全画面、または素材のサイドピーク | その素材（素材の **メモ** タブにも並びます）。ノートの本文で書いている最中は、ピークを開いていても、カーソルのあるブロックに付きます |
| ノートで、ブロックにカーソルがある・文字を選んでいる | そのブロック（ブロックのメニューの **メモを追加** と同じ） |
| ノートで、空の行にいる・カーソルが本文にない | そのノート |
| 一覧・ホーム・テンプレートの編集・アーカイブやゴミ箱のノート | どこにも付けない（これまでどおりの単独のメモ） |

本文の欄の上の小さなチップに、付け先が出ています。チップの **×** を押すと付け先が外れ、メモは単独で保存されます。

- 保存できると、右下に「メモに保存しました」と短く出ます。
- 保存できなかったときは、ダイアログは開いたままで、書いた文も残ります。右下に「メモを保存できませんでした」と出るので、もう一度 `⌘Enter` で送り直せます。

![段落にカーソルを置いたままショートカットで開いたメモのダイアログ。本文の上のチップに付け先の段落が出ていて、その下にメモの文章と、保存のキー操作の案内がある。](/screenshots/quick-memo-target.png)

ほかの入口:

| 入口 | 場所 |
|---|---|
| **メモ** の横の **+** | サイドバーの **素材** タブで **メモ** の行にカーソルを合わせると出ます |
| **メモを作成** | メモギャラリー上部のボタン |
| **File → New Memo** | [デスクトップアプリ](/ja/desktop-app)のネイティブメニュー。ショートカットは同じ `⌘⇧M` |
| **メモに保存** | [素材](/ja/materials-and-citations)で PDF や Web ページを読みながらテキストを選択し、引用としてメモにする |

## スマホの画面

スマホのブラウザで[アプリ](https://kumagallium.github.io/Graphium/app/)を開きます。デスクトップの[設定 → ストレージ → スマホやブラウザから送る → スマホから送る](/ja/settings)にある QR コードを読み取ると、すぐ開けます。

スマホでは、Graphium は記録のためのホームを表示します。**これまでの記録** に記録したものが並び、画面下部に記録用のバーが固定されます。記録の入口は 6 つあります。**書く**・**URL**・**写真**・**動画**・**音声**・**ライブラリ** です。

![記録の履歴と記録バーが並ぶスマホの画面](/screenshots/mobile-capture.png)

- **書く** はメモ用のテキスト入力を開き、**URL** はリンクを保存します。
- **写真**・**動画** はスマホのカメラを直接開くので、実験台やホワイトボードは 2 タップの距離です。**ライブラリ** は写真ライブラリから選びます。
- **音声** <Badge type="tip" text="v0.26.0 (2026-07-30) で追加" /> は、Graphium の中で録音します。タップで開始し、もう一度タップで停止します。聴き返してから **これを使う** を押してください。うまく録れていなければ **録り直す** を押します。録音は 10 分で自動的に止まります。録音中は、画面が自動で消えないようにしています。画面を消したり別のアプリに切り替えたりすると、スマホがマイクを止めることがあるので、止めるまで Graphium を開いたままにしてください。
  - 最初のタップで、ブラウザがマイクの使用許可を尋ねます。
  - 以前に拒否している場合は、サイトへの許可を有効にしてから、もう一度お試しください。

![スマホでメモを書く](/screenshots/mobile-memo-input.png)

ここで記録したものは、すべてデスクトップへ渡ることを前提にしています。記録した瞬間に**送信キュー**に入り、スマホ側に保存されます。そのため、ブラウザを閉じても、オフラインになっても失われません。

- 未送信のものは、件数付きでホーム上部に留まります。各行には、状態が表示されます。状態は **待機中**・**送信中...**・**送信済み**・**失敗**（再試行できます）のどれかです。
- **送信** を押すと、キューがクラウドストレージにアップロードされます（次のセクション）。
- 送信し終えたものは消えずに一覧に残るので、どこまで渡ったかが分かります。不要になった行は **履歴から削除** で消せます。
- ヘッダーのチップで、ストレージが接続済みかどうかが分かります。

::: tip アプリのようにインストールできます
Graphium はインストール可能な Web アプリ（PWA）です。スマホのブラウザの「ホーム画面に追加」を使うと、ブラウザの枠なしで全画面起動します。
:::

::: warning 記録は送信するまで手元に留まります
記録は、送信するまで**そのスマホの**キューに留まります。自動でデスクトップに届くわけではありません。ストレージを一度接続し、**送信** をタップして移してください。データの置き場所は[保存と同期](/ja/storage-and-sync)を参照してください。
:::

## メモギャラリー {#the-memo-gallery}

デスクトップでは、サイドバーの **素材** タブにある **メモ** をクリックします。隣の数字が件数です。メモは、付箋のカードが壁に並ぶように表示されます。**ギャラリー** と **リスト** の表示を切り替えられます。

![付箋のカードが壁のように並ぶメモギャラリー](/screenshots/memo-gallery.png)

**ギャラリー** 表示でも、カードにカーソルを合わせると、左上にチェックボックスが出ます。何か選んでいる間は、出たままです。ヘッダーのチェックボックスで全件を選べます。**ギャラリー** と **リスト** を切り替えても、選んだものは残ります。 <Badge type="tip" text="v0.61.0 (2026-09-08) で追加" />

複数のメモをまとめて選び（カードの上をドラッグ、または Shift+クリック）、一括で操作できます。

| 操作 | 内容 |
|---|---|
| **フォルダに入れる** <Badge type="tip" text="v0.56.0 (2026-09-06) で追加" /> | 選んだメモをフォルダに入れる。ノートや素材と同じフォルダを共有します |
| **アーカイブ** | 削除せずに、ギャラリーから外す |
| 削除（右端のゴミ箱のボタン） | 完全に削除する。すでにノートに挿入済みのメモがあっても、ノート本文には影響しない |
| **ナレッジ化** | 選んだメモから、知識エントリを[ナレッジ層](/ja/knowledge-layer)へ直接取り出す。ノートは作られない |

![Memos ギャラリーの上部。ヘッダーの全選択がオンで、選択バーに「3 selected」と選択解除、「Add to folder」「Add to Knowledge」「Archive」と右端のゴミ箱のボタンが並ぶ。3 枚のメモカードがすべてチェックされ、1 枚には赤い「Bread」のフォルダ表示が付く。](/screenshots/memo-gallery-selection.png)

<Badge type="tip" text="v0.56.0 (2026-09-06) で追加" /> メモを作るときは、**メモを作成** ボタンの左でフォルダを選べます。最初に選ばれているフォルダは、そのとき見ているものによって決まります。ノートの **このフォルダに新規** と同じ規則です。

- ノートの中から作ると、そのノートのフォルダです。
- サイドバーでフォルダを開いていると、そのフォルダです。
- どちらでもなければ、空のままです。

ほとんどの場合は、そのまま ⌘+Enter で済みます。フォルダに入れたメモには、カードにフォルダ名が付き、ヘッダーのフォルダアイコンで絞り込めます。フォルダの名前を変えたり消したりすると、ノート・素材と同じように、メモも一緒に動きます。

メモを 1 件クリックすると、詳細が開きます。本文を編集でき、**編集履歴** が残ります。また、2 つのタブを切り替えられます。**ネットワーク** タブには、このメモがどのノートに挿入されたかを示す小さなグラフが出ます。もう 1 つは **履歴** タブです。

各ノートの右パネルにも **メモ** タブがあり、そのノートに紐づくメモが表示されます。

## メモをノートに入れる

メモは、ノートを書くための材料です。あとでノートに取り込みます。

- **スラッシュメニュー**: エディタで `/memo` と打ちます。**メディア** の下にある **メモ**（説明は「保存済みメモから挿入」）から **メモを選択** のピッカーが開き、検索して選べます。
- **ギャラリーから**: ノートを開いた状態でメモの詳細を開き、**ノートに挿入** をクリックします。

ギャラリーから入れるときは、Graphium が **挿入してメモを残す** か **挿入してメモを削除** かを尋ねます。同じ着想を別の場所でも引用しそうなら、残してください。スラッシュメニューから入れるときは、常にメモを残します。

メモは、改行もそのまま、1 つの引用ブロックとして入ります。出典を持つメモ（リーダー表示から **メモに保存** で作ったもの）は、本文の後ろに出典が表示されます。

### 元のメモとつながったままの引用 <Badge type="tip" text="v0.109.0 (2026-10-30) で追加" /> {#quoted-memos}

引用ブロックは、どのメモから入れたかを覚えています。左の線がメモの色（黄土色）になります。ブロックにカーソルを合わせるか、ブロックを選ぶと、右上に小さな **メモ** のボタンが出ます。押すと、いまのメモの内容と、引用した日時が見られます。

- **メモを開く** を押すと、元のメモをサイドで開きます。
- 引用したあとでメモを書き直していると、ボタンに小さな点が付き、小窓に **元のメモが更新されています** と出ます。**本文に反映** を押すと、ブロックの中身がいまのメモの本文に置き換わります。押すまでは何も変わりません。ノートの本文は書き手のものだからです。
- 元のメモが削除されたときは、小窓がそのことを知らせます。ノートの本文はそのまま残ります。
- **紐づけを外す** を押すと、つながりだけが外れ、本文は残ります。

![左に黄土色の線がある引用ブロックと、そのメモのボタンから開いた「引用したメモ」の小窓。元のメモが更新されたことを知らせ、本文に反映（図では Update this quote）・メモを開く・紐づけを外すのボタンとメモの本文が出ている。](/screenshots/memo-linked-quote.png)

引用したメモは、ノートのグラフ（**近傍**）にも、ノートに向かうメモのノードとして出ます。押すとメモが開きます。

- ノートやそのブロック・つながり、グラフに出ている素材に付けたメモも、グラフに出ます。細く薄い線でつながります。引用は、通常の実線です。
- 同じノートや素材に 6 件以上付いているときは、**メモ n 件** の 1 つのノードにまとまります。押すと、メモタブが開きます（素材なら、その素材が開きます）。
- アーカイブやゴミ箱のノートでは、小窓は見るだけです。

![ノートの近傍グラフ。中心にノート、付箋のアイコンで描かれた 4 件のメモのノードが細い線でつながり、貼ったパンの写真がサムネイルのノードで出ている。](/screenshots/neighborhood-memos.png)

### ブロックにメモを紐付ける

メモは、ノート全体ではなく、特定のブロックへの注釈にもできます。ブロックのドラッグハンドル（⠿）のメニューを開き、**📝 メモを追加** を選びます。メモがブロックを追いかける仕組みは、[素材と引用](/ja/materials-and-citations)を参照してください。

## メモは引用できるソース

メモは使い捨てのテキストではなく、来歴を持ちます。走り書き用のメモ帳ではなく Graphium で記録する意味は、ここにあります。

- **メモに保存** で作ったメモは、どの素材から引用したかを、PDF ならページ単位まで覚えています。
- ノートへの挿入は毎回記録されます。そのため、メモは自分が使われたノートを知っています（使用件数と **ネットワーク** タブ）。
- **ナレッジ化** を実行すると、できた知識エントリは、そのメモを出典として記録します。そのため[来歴グラフ](/ja/labels-and-provenance)は、知見からメモを経て、記録した時点までさかのぼれます。

## 記録をデスクトップに送る <Badge type="tip" text="v0.23.1 (2026-07-29) で追加" /> {#sending-captures-to-your-desktop}

モバイル送信を使うと、スマホからデスクトップまで、記録が一続きでつながります。スマホで記録したものが、自分のクラウドストレージを通って、デスクトップの受信箱に届きます。

送信は、最近のスマホのブラウザであれば動きます。ただし、**受信には[デスクトップアプリ](/ja/desktop-app)が必要**です。ローカルの同期フォルダを読めるのは、デスクトップだけだからです。

最初から最後までの流れは、次のとおりです。

1. **スマホでストレージを接続する（一度だけ）。** スマホのヘッダーの歯車（またはキューの **ストレージに接続** ボタン）をタップします。**ストレージを選ぶ** のピッカーに **Google Drive** が出ます（OneDrive は **準備中** と表示されます）。自分の Google アカウントでサインインします。Graphium がアクセスできるのは、自分が作ったファイルだけです（`drive.file` スコープ）。既定では、切断するまで接続が続きます。くわしくは[つないだままにする](#stay-connected)を見てください。歯車の奥の設定シートには接続状態も表示され、**変更** や **切断** ができます。クライアント ID の上書きは、ふだん触る必要はなく、折りたたまれた **詳細設定** の中にあります。
2. **記録して送る。** キューの **送信** をタップすると、自分の Drive の `Graphium/Inbox` フォルダに送られます。転送は TLS を使います。ファイルは、*自分が管理する*ストレージに、普通のファイルとして置かれます。
3. **フォルダをデスクトップに同期する。** クラウドのクライアント（たとえば Google ドライブ デスクトップ版）を動かして、そのフォルダをデスクトップのディスク上に置きます。
4. **Graphium にその場所を教える。** デスクトップの[設定 → ストレージ](/ja/settings)で **スマホやブラウザから送る** を展開し、**スマホから送る** を開くと、**受信フォルダ** のピッカーがあります。クラウドストレージが同期しているフォルダを選ぶと、Graphium はその中の `Inbox` サブフォルダを読みます。同じセクションの **接続はスマホ側で行います** には、スマホで Graphium を開くための QR コード（**URL をコピー** 付き）があります。
5. **取り込む。** ファイルが届くと、デスクトップのサイドバー（**取り込み** の行の右端）の **モバイル** アイコンに、未処理の件数が表示されます。押すとモバイルの受信箱が開くので、1 件ずつプレビューし、**全部取り込み** か **選択したものを取り込み** を実行します。<Badge type="tip" text="v0.173.7 (2026-11-27) で追加" /> 要らないものは、チェックを付けて **選択したものを取り込み** の横のごみ箱を押すと、確かめたあと、取り込まずに `Inbox` フォルダから消えます。

取り込んだ写真は、取り込みのあとで自動で文字が読み取られます（OCR）。音声（.m4a・.weba・.wav など）も、自動で文字になります。これはデスクトップ版だけの機能です。文字起こしモデルが要るので、音声が届いたときに Graphium が取得します（[音声ノート](/ja/voice-notes#settings)を見てください）。1 本ずつ順に処理し、1 本は 2 時間までです。モデルの取得中は **文字起こしモデルを取得しています（約 574 MB、N%）** と出ます。止めるときは、設定の **音声ノート** にある **取り消し** を押します。文字起こしできなかった音声があると、その知らせが出ます。2 時間を超えていたときと、モデルがまだ使えないときは、そのことも書かれます。どの場合も音声は素材に残るので、あとで開いて **文字起こし** を押せます。

取り込んだものは、次のようになります。

- 写真・動画・音声メモは、[素材](/ja/materials-and-citations)になります。
- 書いた記録は、通常のメモや URL のブックマークになります。
- 重複は自動でスキップされ、トーストが **取り込み・スキップ・失敗** の件数をまとめます。
- 受信箱が空なら、**新しいものはありません** と表示されるだけです。

スマホの画面上部にある **送り先** <Badge type="tip" text="v0.55.0 (2026-09-04) で追加" /> でフォルダを選んでおくと、届いたものはそのフォルダに入った状態になります。写真・動画・音声・URL は素材として、書いた記録はメモとして入ります。

- 一覧には、その端末で前に使ったフォルダが並びます。スマホからも同じ保管場所につながっている場合は、そのフォルダも並びます。
- **＋ 新しいフォルダ…** で、その場でフォルダを作ることもできます。
- 選んだフォルダは、切り替えるまで覚えているので、送るたびに選ぶ必要はありません。

![デスクトップの Mobile 受信画面。写真のサムネイル、スターターのメモ、Sourdough Hydration, Explained の URL、動画の 4 件が並び、Import selected (0) と Import all ボタンがある。](/screenshots/mobile-inbox.png)

### ノートを開いたまま、届いたものを入れる <Badge type="tip" text="v0.171.0 (2026-11-25) で追加" /> {#inbox-beside-the-note}

実験室で撮った写真を、席に戻ってすぐノートに並べたいときは、受信箱を開き直す必要はありません。受信フォルダを接続していると、ノートの右端のアイコンの列に **モバイル** が出ます。届いているものがあるときは、アイコンに点が付きます。

押すと、まだ取り込んでいないものが、新しい順にサムネイルで並びます。ここからノートに入れると、取り込みも同時に済みます。

- **ノートへドラッグする。** 落とした位置に入ります。
- **ダブルクリックする。** カーソルのある場所の下に入ります。タイルの右上の **＋**（**ノートに入れる**）でも同じです。
- **まとめて入れる。** タイルの左上のチェックか、⌘（Windows は Ctrl）を押しながらのクリックで複数を選びます。選んだものをドラッグするか、下の **選んだ N 件をノートに入れる** を押すと、撮った順に上から並びます。
- クリックは選ぶだけで、ノートは変わりません。
- **使わずに削除する。** <Badge type="tip" text="v0.173.7 (2026-11-27) で追加" /> 1 件か何件かを選んで、右下のごみ箱を押します。確かめたあと、同期フォルダの `Inbox` フォルダから消えます。Graphium には何も残りません。

写真・動画・音声・ファイルは素材のブロックとして、書いた記録は[元のメモとつながった引用](#quoted-memos)として、URL はブックマークのカードとして入ります。入れたものは受信箱から消え、素材やメモの一覧にも残ります。

スマホから届いたものは、ウィンドウに戻ったときと、開いている間の約 20 秒ごとに、自動で並びます。サイドバーの件数と、全画面の受信箱も同じように更新されます。

既定では、取り込んだファイルは受信箱から削除されます。中身はすでにライブラリに入っているためです。控えを残したい場合は、**処理済みファイルを _imported/ に残す** をオンにしてください。場所は、受信フォルダの設定です（設定 → ストレージ → スマホやブラウザから送る → スマホから送る）。

### つないだままにする {#stay-connected}

Google のブラウザ用サインインでスマホが受け取る鍵は約 1 時間で切れるため、これまでは何度もつなぎ直す必要がありました。いまは新しくつなぐと、スマホがつながったままになります。**つないだままにする** は既定でオンです。

しくみは次のとおりです。

- 初めてつなぐとき、Google はスマホに 1 回きりのコードを渡します。スマホはそのコードを Graphium が動かす小さなサーバーに送ります。サーバーが Google とそのコードを引き換え、アクセス用の鍵と、その鍵を更新するための鍵の 2 つをスマホに返します。
- アクセス用の鍵が切れると、スマホは更新用の鍵を同じサーバーに送り、新しいアクセス用の鍵を受け取ります。画面は出ません。
- 更新用の鍵は、スマホのブラウザの保存領域に置かれます。設定シートの **切断** を押すと、Google に取り消しを送り、スマホからも消します。Google アカウントの「サードパーティのアクセス」からも取り消せます。

そのサーバーを通るものと通らないものは、次のとおりです。

| 何が | そのサーバーを |
|---|---|
| 1 回きりのコードと、2 つの鍵 | 通ります |
| 送る写真・メモ・URL | 通りません（スマホから Google ドライブへ直接届きます） |
| ノート、メールアドレスや名前 | 通りません（Graphium が Google に求めるのは、自分が作ったファイルへのアクセスだけです） |

- サーバーは何も保存せず、ログも残しません。宛先は Google だけで、ほかの Web サイトがあなたのブラウザからこのサーバーを呼ぶことはできません。サーバーを預けている Cloudflare には、要求ごとの IP アドレス・時刻・User-Agent が見えます。また、要求が来る回数を制限するために、送信元の IP アドレスごとに数えています（Graphium のコードが IP アドレスを保存・記録することはありません）。
- 更新用の鍵そのものを手に入れた人は、このサーバーを通して新しいアクセスの鍵を受け取れます。そのため、更新用の鍵はスマホの中だけに置きます。スマホを手放すときやなくしたときは、**切断** を押すか、Google アカウントの側で取り消してください。
- 鍵が届くのは、この方式で作ったファイル、つまりドライブの `Graphium/Inbox` に送ったものだけです。ドライブのほかのファイルには届きません。この方式は、1 時間で切れる方式とは別の Google の client を使います。鍵の届く範囲を、それらのファイルに限るためです。
- サーバーに保証はなく、予告なく止まることがあります。新しい鍵を取り直せないあいだ、送るものはスマホのキューに残り、取り直せたときに送られます。
- Google が更新用の鍵を無効にしたとき（自分で取り消した、約 6 か月使わなかったなど）は、もう一度 **接続** を押します。

**オフにするには。** スマホの設定シートで **つないだままにする** をオフにすると、1 時間で切れる従来の方式に戻ります。このとき、鍵は Graphium のサーバーを通りません。自分の Google client ID を設定している場合は、従来の方式のままです。

**以前からスマホ取り込みを使っている人。** 自動で判断できるのは、このスマホに以前の接続の記録が残っている場合だけです。その場合は、自分で **つないだままにする** をオンにするまで変わりません。オンにすると、ドライブに新しい `Graphium` フォルダができます。この方式の接続では、前の接続が作ったフォルダが見えないためです。以前に **切断** していて記録が残っていない場合は、次につないだときに **つないだままにする** になり、やはりドライブに新しい `Graphium` フォルダができます。ドライブに `Graphium` フォルダが 2 つ見えたら、デスクトップの **スマホから送る** で、**受信フォルダ** を新しいほうに選び直してください。設定で **つないだままにする** をオフにしてつなぎ直す方法もあります。

::: tip クラウドのアカウントが無くても大丈夫
キューは便利なだけで、必須ではありません。スマホの共有シートから、同期された `Graphium/Inbox` フォルダに写真を手で保存することもできます（写真 → 共有 → ファイル / Drive アプリ）。デスクトップの受信箱は、そうして置いた写真も、キューで送ったものと同じように取り込みます。
:::

::: info なぜ間にクラウドストレージを挟むのか
記録そのものが、Graphium のサーバーを通ることはありません。記録は、*自分が管理する*ストレージ（自分の Google Drive）を通ります。デスクトップは、自分のディスク上のフォルダを読むだけです。スマホが Graphium のサーバーに送るのは、[つないだままにする](#stay-connected)で説明している Google の鍵だけで、オフにできます。[保存と同期](/ja/storage-and-sync)を参照してください。
:::
