# 実験ノートとして使う

何かを試した記録は、あとから「この結果は、いつからあったのか」と問われることがあります。論文の査読や研究公正の確認、共同研究の取り決め、特許の先使用の説明などです。研究に限らず、レシピや製品の試作、設計の検討でも同じ場面があります。

紙の実験ノートは、日付を書いて綴じ、ページを破れないようにして、この問いに答えてきました。電子の実験ノート（ELN、Electronic Lab Notebook）は、同じ役目を画面の上で果たす道具です。

このページでは、Graphium をその用途にどこまで使えるかを整理します。結論を先に書くと、**「あとで証拠として出せる、研究の記録」には使えます**。ただし、**規制に対応した電子実験ノートではありません**。

## できること・できないこと

| 実験ノートに求められること | Graphium | 使う機能 |
|---|---|---|
| 日付つきで記録が残る | ○ | 保存はすべて履歴に残ります（[履歴とバージョン](/ja/notes-and-editor#history-and-versions)） |
| 何をどう作ったかの経緯が残る | ○ | 手順・材料・結果を来歴（PROV）としてつなげます（[ラベルと来歴](/ja/labels-and-provenance)） |
| 区切りの時点を残す | ○ | **今の状態を履歴に残す**（[くわしく](/ja/notes-and-editor#version-snapshots)） |
| 書き換えたら分かる | ○ | **証拠として固定する** と、内容のハッシュが記録されます（[くわしく](/ja/notes-and-editor#seal-as-evidence)） |
| 「この日より前にあった」を第三者が確かめられる | ○ | 固定すると、外部の時刻証明が 2 つ付きます。書き出した zip は Graphium が無くても確かめられます |
| 誰が書いたかを証明する | × | 名前は自己申告です（[設定](/ja/settings) → **共有** → **あなたの名前**）。電子署名や本人認証はありません |
| 記録を消せない | × | 手元のファイルは、持ち主が消せます。途中の固定を消すと、固定の連なりに穴が空くので分かります。ただし、いちばん新しい固定を消しても分かりません |
| 第三者（証人）が確認の署名をする | × | 紙のノートの「確認者の署名」に当たる仕組みはありません |
| 記録の漏れが無い | △ | 固定されるのは、ボタンを押した時点だけです。押さなかった日の記録には、外部の時刻証明が付きません |
| 規制への対応（21 CFR Part 11・GLP など） | × | 監査証跡・電子署名・アクセス管理の要件は満たしていません。対応しているとも名乗っていません |

ここでいう「証明」は、**「この時刻より前に、この内容があった」** ということだけです。内容が正しいこと、自分で考えたこと、AI の生成物でないことは、証明の対象に入りません。

## おすすめの使い方

1. **ふだんどおりに書きます。** 手順はステップブロックに、材料と結果はラベルを付けて残すと、あとで経緯を説明しやすくなります。
2. **区切りで時点を残します。** 実験の 1 回分が終わったとき、結果が出たとき、人に見せる前など、意味のあるところで `⌘⇧S`（Windows は `Ctrl+Shift+S`）を押します。名前を付けておくと、あとで探しやすくなります。
3. **証拠にしたい時点を固定します。** 履歴の行にある鍵のボタン（**証拠として固定する**）を押します。外へ送るのは内容のハッシュだけです。本文も素材も送りません。
4. **書き出した zip を、別の場所にも置きます。** 研究室の NAS や外付けのディスクなどです。固定した記録も手元のファイルなので、端末が壊れたときに備えて、写しを残してください。
5. **ときどき確かめます。** **固定した内容を確かめる** を使うと、記録と時刻の証明が合っているかを、アプリの中で照合できます。

固定するまでは、どこにも何も送りません。この用途に使わない人は、ボタンを押さなければ、今までどおりです。

## 向いている場面・向いていない場面

**向いている場面**

- 自分やチームの研究記録を、あとで「この日より前にあった」と示せる形で残したい
- 論文の投稿や共同研究の前に、その時点の記録を第三者に渡したい
- アイデアの先取りや、試作の経緯を説明する材料を手元に持っておきたい

**向いていない場面**

- 医薬品・医療機器の開発など、規制当局への提出に使う記録（Part 11・GLP・GMP の対象）
- 所属機関が、特定の ELN や承認の手順（上長の確認署名など）を定めている場合
- 書いた人を本人として証明する必要がある場合

所属機関に記録の規程があるときは、その規程が優先されます。Graphium の固定は、規程の代わりではありません。規程が求めることに足りるかどうかは、所属機関の担当の方に確かめてください。

## 時刻の証明について

固定すると、性質の違う 2 つの時刻証明が付きます。どちらも無料の公開サービスで、アカウントも API キーも要りません。

| | すぐに付く証明 | 数時間で確定する証明 |
|---|---|---|
| サービス | [FreeTSA](https://freetsa.org/)（RFC 3161 の時刻証明局） | [OpenTimestamps](https://opentimestamps.org/)（Bitcoin に記録） |
| 何を信じるか | 時刻証明局の署名 | Bitcoin のブロック |
| 確かめ方 | `openssl ts -verify` | `ots verify` または opentimestamps.org |

1 つの運営者だけに頼らないように、2 つを併用しています。片方のサービスが止まっても、もう片方の証明は残ります。確かめ方の手順は、[証拠の zip の中身と、Graphium なしでの確かめ方](/ja/notes-and-editor#seal-as-evidence)にまとめています。

**サービスに送るもの・送らないもの**

| | 内容 |
|---|---|
| 送るもの | 固定した内容から計算したハッシュ（SHA-256、32 バイト）だけです。OpenTimestamps には、そのハッシュに乱数を混ぜた値を送ります。2 つのサービスの記録を突き合わせても、結び付けられないようにするためです |
| 送らないもの | ノートの本文・題・素材・あなたの名前。ハッシュから中身を戻すことはできません |
| サービスに見えるもの | 通信元の IP アドレスと時刻（どの端末から、いつ固定したか） |
| 送るタイミング | 次の 3 つのときです。**証拠として固定する** を押したとき。確定待ちの証明を取りに行くとき（カレンダーが前に返した値を送るだけです）。**固定した内容を確かめる** を押したとき（このときは Bitcoin のブロックの情報を取りに行くだけで、ハッシュは送りません） |

くわしくは[プライバシー](https://github.com/kumagallium/Graphium/blob/main/docs/PRIVACY_ja.md)をご覧ください。

::: warning Web 版では時刻の証明が付きません
公開の時刻証明サービスは、ブラウザからの直接の通信を受け付けません。Web 版でも、固定そのものはできます。書き換えれば分かりますが、時刻の証明は付きません。時刻の証拠が要るときは、[デスクトップ版](/ja/desktop-app)をお使いください。
:::

## これから

今の形でいちばん大きな弱点は、固定を押し忘れた日の記録に、時刻の証明が付かないことだと考えています。次の 3 つは、検討している段階です。

- その日に書いたノートをまとめて固定する仕組み
- 書いた人の署名
- 共同研究者による確認の署名
