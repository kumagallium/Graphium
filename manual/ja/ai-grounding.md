# 世界照合

ノートからは、知見や洞察が生まれます。では、それは世界がすでに知っていることと、どう関係しているのでしょうか。世界照合は、ナレッジの 1 項目を外部の情報源（Wikipedia、OpenAlex、任意で Web 検索）と突き合わせ、判定（verdict）を付けます。

判定からは、これが世界ではすでに知られているのか、支持されているのか、それとも争われているのかが分かります。どこを深掘りするかを決める材料になります。

verdict は、真偽を言い切るものではありません。位置づけの手がかりとして扱ってください。示されるのは、その主張が知識ベースに対してどこに位置するかです。主張が成り立つかどうかの最終判断は、いつも自分で下します。

::: info 必要なもの
世界照合は Graphium の AI 機能の一部なので、[デスクトップアプリ](/ja/desktop-app)と、登録済みモデルが 1 件以上必要です（[AI のセットアップ](/ja/ai-setup)を参照）。

Wikipedia と OpenAlex からの根拠は、API キーなしでそのまま使えます。Web 検索の MCP サーバー（たとえば Tavily）を追加すると、根拠の範囲が一般の Web まで広がります。

**設定** → **AI** の、既定で畳まれている **先行公開の機能** にある **世界照合を使う** スイッチも、オンにしておく必要があります。初めて使う人はオフ、以前から使っている人はオンです。下で説明する **世界照合** ボタンが見当たらないときは、まずこれをオンにしてください。
:::

## 主張を世界と突き合わせる <Badge type="tip" text="v0.8.0 (2026-05-21) で追加" />

サイドバーの **ナレッジ** タブから、**知見** または **洞察** の項目を開きます。本文の上にあるバナーの、**再生成** の隣に **世界照合** ボタンがあります。

![エディタで開いた知見。バナーに世界照合ボタンと verdict チップが並んでいる](/screenshots/world-grounding-verdict.png)

ボタンを押すと照合が始まり、結果がその項目に保存されます。保存されるのは verdict・理由・出典です。実行中は、進捗のトーストが状況を伝えます。

**要約** は照合できません。要約は、現在は新規生成を停止しているページの種類です（詳しくは[ナレッジ層](/ja/knowledge-layer)を参照）。要約は世界について何かを主張するものではなく、自分のノート 1 件の内容を説明するものだからです。

複数の項目をまとめて照合することもできます。

- 知見・洞察の一覧には **世界** 列があり、各行の最新の verdict が出ます。verdict の強さで並べ替えられます。
- チェックボックスで行を選ぶと、バーが出ます。そのバーの **世界照合** をクリックします。
- もう一度実行すると、前の verdict が上書きされます。このボタンは「付け直し」も兼ねます。

## verdict を読む

verdict はバナーのチップとして表示され、知識ベース側の立場という形で示されます。チップにカーソルを合わせると、**KB から見た位置づけ** と理由が見られます。

| チップ | 意味 |
|---|---|
| **確立した知識と整合** | 教科書レベルで確立した知識と合っている。 |
| **支持された知識と整合** | 公表された裏付けはあるが、そこまで定まってはいない知識と合っている。 |
| **KB は裏付けが弱いと見る** | 知識ベースが見つけた裏付けは、弱いものだけだった。 |
| **KB に反例がある** | 知識ベースが、この主張に反する証拠を持っている。 |
| **照合済 · KB マッチなし** | 照合はしたが、一致するものがなかった。支持も反証もされていない。 |

全体像を見るには、項目の一番下までスクロールします。**世界照合 詳細** のセクションに、次のものが並びます。

- **理由**
- **参考文献**（それぞれ開けるリンク）
- **マッチした語彙**
- **照合元**

照合元を見ると、その答えがどこから来たかが分かります。ローカルの知識ベースから来たのか、Web の根拠に裏打ちされた判定から来たのか、モデルが自分の知識で答えたのかの 3 通りです。

2 つの洞察が同じ世界の事実につながったときは、Graphium がそれらを結びます。**同じ世界事実に接続した洞察 (n)** のセクションに、世界の同じ一点に触れた、ほかの洞察が並びます。1 つだけで完結する AI の回答では、このようなつながりは残せません。

## 出典照合: 出典に実際に書いてあるか <Badge type="tip" text="v0.77.0 (2026-09-17) で追加" />

世界照合は、主張が外の知識に照らして成り立つかを確かめます。**出典照合** が確かめるのは、もっと狭いことです。このナレッジ項目が引いている出典に、実際にそう書いてあるかどうかです。

外部の知識には一切触れません。命題が正しいかどうかも判定しません。判定するのは「引かれた出典に書いてあるかどうか」だけです。

照合するのは **知見** と **トピック** だけです。

- 知見は、全体を 1 つとして照合します。title と本文を、**由来** に並ぶすべての出典ノートと突き合わせます。
- トピックは、文ごとに照合します。本文中の、**参考文献** セクションより前にある各文のうち、メンバーの知見を引用している文だけが対象です。その文を、引用先の知見の本文と突き合わせます。
  - 引用は、リンクの形でも、文の直後に知見のタイトルが文字としてそのまま置かれている形でも、認識します。
  - 何も引用していない定義の段落は照合しません。
- **洞察は対象外です。** 洞察は複数の知見をまたいだ一般化で、1 つの出典を言い換えたものではありません。突き合わせる相手の出典テキストが、そもそも存在しないためです。

実行のしかたは 2 つあります。

- 知見・トピックのバナーにある **出典照合** ボタン。AI が使えるときだけ表示され、**世界照合** の隣にあります。
- **手入れ** 画面の **手入れ** タブにある **手動で照合する**（後述）。

既定では、取り込み時にも起動時にも自動では走りません。結果が出るのは、自分で頼んだときだけです。ただし、設定の **自動で出典照合する** をオンにすると、自動でも走るようになります（既定オフ。後述の「自動で出典照合する」を参照）。

AI をオフにするとボタンは消えますが、すでに記録した結果はそのまま表示され続けます。

**バッジの読み方。** 出典照合ボタンの隣のバッジは、次の 5 つの判定のどれかを示します。

| バッジ | 意味 |
|---|---|
| **出典と異なる** | 引かれた出典が、この主張と食い違うことをはっきり述べている。5 つの中でいちばん目を引く色にしてあります。主張が自分の出典と食い違っているのは、いちばん意外な結果だからです。 |
| **出典に見当たらない** | 出典は読めたが、そうは書かれていない。 |
| **出典に書かれている** | 出典にそう書かれている。 |
| **判定できなかった** | 出典は読めたが、どちらとも判定がつかなかった。 |
| **出典を開けなかった** | 出典そのものを照合できなかった（理由は下記）。 |

項目の下部にある **出典照合 詳細** を開くと、出典ごとの内訳が並びます。内訳は、判定と短い理由です。モデルの引用が、ノートの特定のブロック 1 つに絞り込めたときは、**該当箇所へ** のリンクも付きます。

- このリンクが開くのは、リンク先のノート・PDF・Word ファイル・知見までです。その中の特定のブロックまで自動でスクロールする仕組みは、いまのところありません。
- 開けない出典は、リンクとして表示されません。記録が無いもの、AI チャット由来のもの、裏づけのノートが残っていない `⌘K`（Windows/Linux は `Ctrl+K`）の回答が、これにあたります。
- トピックでは、各エントリに、照合した **文** も表示されます。ページ全体ではなく、その特定の 1 文です。

<Badge type="tip" text="v0.80.0 (2026-09-18) で追加" /> 出典が PDF や Word ファイルのときは、引用の直下に、その出典のどこにあったかも表示されます。たとえば **12 ページ**、**12〜13 ページ**、**第 3 段落** のような表示です。

この位置は、モデルに書かせたものではありません。照合のときに読んだ原文から、機械的に割り出したものです。判定には影響せず、該当箇所を探しやすくするための表示です。まったく同じ文言が出典の中の複数の箇所（別のページや段落）にあるときは、どちらを指しているか決められないため、この表示は出ません。

![出典照合の詳細欄。3 件の出典それぞれで、引用の下に 12 ページ・7〜8 ページ・第 12 段落と位置が出ている](/screenshots/source-check-quote-location.png)

**「出典を開けなかった」の内訳。** 次の場合は、判定そのものを試みず、その状態のまま記録されます。

| 理由 | いつ起きるか |
|---|---|
| 出典が見つからない（削除・ゴミ箱） | 引かれたノート・PDF・Word ファイル・知見がゴミ箱にあるか、すでに存在しない |
| 元の会話を辿れない（AI チャット由来） | 出典が AI チャットで、元をたどるための参照キーを Graphium が持っていない |
| 原文を読み出せなかった | URL の再取得や、PDF/Word の再抽出に失敗した |
| 照合できない種類の出典 | 出典照合が扱わない種類の ID |
| 出典の本文が空 | 出典は読めたが、中身が空だった |
| AI の回答から作った知見（原文なし） | その知見が `⌘K` の回答から作られたもので、回答そのものは保存されていない。回答を出したノートと突き合わせると、誤って「見当たらない」と判定してしまう |
| 出典の記録が無い | 知見に引いたノートが 1 件も無い、またはトピックのその文がメンバーの知見を 1 件も引用していない |

出典照合は、毎回、原文をキャッシュに頼らず取り直します。

- PDF と Word は、取り込みと同じ抽出器で読み直します。
- URL は、以前保存したコピーではなく、実際に取り直した内容と突き合わせます。そのため判定は、いまその URL に何が書いてあるかを映します。

この取り直しに、出典照合が独自の上限を足すことはありません。ノート・Word・Web ページは全文を読みます。PDF は、取り込みと同じ 80,000 字の上限（[よくある質問](/ja/faq)を参照）まで読みます。取り込みが読んだのと同じ範囲と突き合わせることになります。

判定を始める前に、必要になりそうな判定回数の見込みが表示されます。出典を取り出せなかった分は判定せずに飛ばすため、実際の呼び出し回数は、見込みより少なくなることがあります。

**トピックのバッジは、いちばん出来のよい文ではなく、いちばん注意が要る文を映します。** トピックには照合済みの文が複数あり、それぞれ別の判定になりえます。ページのバッジは、それらを平均しません。良い結果に悪い結果を隠させることもせず、いちばん注意が要るものを表示します。

- 1 文でも「出典と異なる」「出典に見当たらない」になれば、ほかの文がすべて「出典に書かれている」でも、そちらがバッジになります。
- トピック全体が「出典に書かれている」になるのは、すべての文がそうなったときだけです。
- 知見は文が 1 つしかないので、この集約で、知見自身のバッジの見え方が変わることはありません。

**まとめて照合する。** 知見・トピックの一覧には **出典照合** 列があり、最新の判定が出ます。並べ替えは、注意が要る順です。**出典と異なる** → **出典に見当たらない** → **判定できなかった** → **出典を開けなかった** → **出典に書かれている** の順になります。

サイドバーの **手入れ** を開き、**手入れ** タブの **手動で照合する** を開くと、次の項目を選べます。

- **対象**: 知見・トピック・両方
- **範囲**: まだ照合していないもの・本文が変わったもの・すべて

選んだあと、件数・判定回数・照合できないものの内訳を含む、実測の計画が出ます。確認してから実行します。実行中は進捗が表示され、途中で中断できます。

この節の機能は、同じタブの **手動で点検する** にある既存のクイック / フル点検とは別のもので、そちらには一切つながりません。1 件の実行と一括実行は同時には走りません。片方が動いているあいだは、もう片方が止まります。

![Knowledge の Claims 一覧を Source check 列で並べた状態。Differs from source・Not in source・Couldn't tell・Source unavailable・Found in source の判定が上から順に並んでいる。](/screenshots/source-check-list.png)

**おまかせで整える（出典照合の部分）。** <Badge type="tip" text="v0.118.0 (2026-11-05) で改善" /> 手入れタブの冒頭にある **おまかせで整える** は、出典照合も行います。

流れは次のとおりです。

1. 点検と手当てのあとに、AI が、まだ照合していないものと、前回の照合から本文が変わったものを照合します。
2. **出典と異なる**・**出典に見当たらない** になったものを直します。

直し方は、ページの種類によって違います。

- **知見**: 裏づける出典が 1 つも無いものは、アーカイブします。知見は 1 件で 1 ページなので、どの出典も裏づけないなら、残すところがないためです。
- **トピック・問答（Q&A）**: 裏づけの無い文があれば、その文だけを 1 回の呼び出しで直します。出典と異なる文は、出典の言い分に合わせて書き換えます。どの出典にも見当たらない文は、外します。そのあと、もう一度照合します。
- **要約**: 資料から作り直して（1 回）、もう一度照合します。

裏づける出典と食い違う出典が両方あるものもあります（たとえば 9 件が裏づけ、1 件が食い違う）。これは、資料どうしで内容が割れている状態です。どちらが正しいかは、Graphium は決めません。ページを書き直して **両方の側を出典つきで書き**、もう一度照合します。書く場所は、トピック・問答・要約なら「食い違い・未解決」の節、知見・洞察なら本文の中です。

そのほかの決まりは次のとおりです。

- **確認した** にしたものは変更しません。
- 照合を中断したときは、その後の修正を行いません。
- 1 件ずつ聞かれることはありません。押したことが、「任せる」の合図になります。
- 終わると、何件直したかが出ます。**実行内容** を開くと内訳があります。
- 全体は、**手入れの履歴** に **おまかせで整える** の 1 回分として残ります。どれでも[取り消せ](/ja/knowledge-layer#undo-maintenance)ます。
- 作り直しや併記をしても出典と一致しないものは、**未対応の項目** としてたたんで表示します。対応は任意です。

AI の呼び出し回数は、次のとおりです。照合で、出典 1 件ごとに 1 回です。手当てで、文の直しと併記は 1 ページ 1 回、要約の作り直しも 1 回です。手当てのあとの照合し直しでも、さらに呼びます。

**結果への対処。** 世界照合と同じく、出典照合の判定にどう対処するかは、自分で決めます。

- **もう一度照合**: 再実行して、古い結果を置き換えます。
- **確認した**: 内容を変えずに、確認済みの印を付けます。
- **結果を消す**: 結果そのものを削除します。

どの知見を直すか、どの出典を信じるかを、Graphium が代わりに決めることはありません。**おまかせで整える** を押したときだけ、その 1 回分の判断を AI に任せます。

**気になる判定でも、一覧からは隠さず、要確認に入れます。** 「出典と異なる」「出典に見当たらない」と判定された知見・トピックも、ほかの一覧からは消えません。AI の判定が間違っている可能性があるためです。こっそり一覧から消えた知見が、それでもトピックやチャットに使われ続けてしまう問題も避けられます。

代わりに、**手入れ** タブの **未対応の項目** のたたみの中に、常設の **要確認** 一覧があります。出典と異なる、出典に見当たらない、の順に並びます。

- 行ごとに、**開く**・**確認した**・**アーカイブ**・**もう一度照合** を選べます。
- 複数の行を選んで、まとめてアーカイブすることもできます。
- ここでのアーカイブは、ほかの画面と同じく、いつでも戻せるアーカイブです。何を消すかは、いつも自分で決められます。**おまかせで整える** を押すことが、その決定にあたります。AI がしたアーカイブは、1 件ずつ取り消せます。

知見・トピックの一覧にも、既定オフの **要確認のみ** フィルターがあります。

![Knowledge upkeep の Upkeep タブ。冒頭に Tidy up for me があり、その下の item(s) worth a look と Check against sources yourself を開いて Review plan を押した後。「56 target(s) · 12 model call(s)」と Run・Cancel が出ており、その下の Needs review (4) に Differs from source と Not in source の行が並び、各行に Open・Confirm・Archive・Check again のボタンがある。](/screenshots/upkeep-source-check.png)

## 自動で出典照合する <Badge type="tip" text="v0.77.0 (2026-09-17) で追加" />

既定では、出典照合は頼んだときだけ動きます。新しくできたナレッジや、変わったナレッジを自動で照合したいときは、次の手順でオンにします。

1. **設定** → **AI** を開きます。
2. 既定で畳まれている **先行公開の機能** を開きます。
3. **世界照合** セクションのすぐ下にある **出典照合** セクションで、**自動で出典照合する** をオンにします（既定はオフ）。

オンにすると、新しく作られた、または更新された知見とトピックが、バックグラウンドで 1 件ずつ出典照合されます。出典 1 件ごとに AI を呼びます。まだ照合していないものも、順に対象になります。

手動の 1 件照合・一括照合とは、同時には動きません。本文を書き換える取り込み（統合・書き直し・トピックの再構成）で結果が消えたものも、再び自動照合の対象になります。

## 仕組み: 育つ知識ベース

世界照合は 2 つの層でできています。この構造が分かると、使うほど速くなる理由も分かります。

1. **まず、ローカルの知識ベースが答える。** 照合はすべて、ローカルの KB との突き合わせから始まります。KB の中身は、手作業で整えた小さな seed と、これまでの照合でキャッシュされたものすべてです。ヒットすれば、すぐに答えが返ります。コストはかからず、モデルも呼びません。
2. **外れたものだけが、モデルに回る。** KB に当てはまらないと、世界照合のモデルが根拠を集めます。Wikipedia と OpenAlex は常に使い、Web 検索の MCP ツールがつながっていれば、それも使います。そして、その根拠に照らして主張を判定します。根拠が何も出てこなければ、モデルは自分の知識で答えます。

モデルの判定は、そのつどローカルの KB にたまっていきます。似た主張を次に照合するときは KB にヒットするので、KB は自分の分野に合わせて育ちます。使うほど、照合は速く、安くなります。

ノートに保存された verdict と、KB のキャッシュは別物です。ノートから verdict を消しても、KB は変わりません。KB のエントリを削除しても、すでにノートに保存された verdict は消えません。

## 自動照合 <Badge type="tip" text="v0.13.3 (2026-06-02) で追加" />

既定では、照合は頼んだときだけ動きます。新しいナレッジができた時点で照合させたいときは、次の手順でオンにします。

1. **設定** → **AI** を開きます。
2. 既定で畳まれている **先行公開の機能** を開きます。
3. **世界照合** セクションで、**自動で世界照合する** をオンにします（既定はオフ）。

このトグルは、**世界照合を使う** がオンのときだけ表示されます。

オンにすると、新しく作られた知見・洞察が、バックグラウンドで 1 件ずつ照合されます。トーストは出ず、静かに進みます。対象は、一度も照合されたことのない項目だけです。先に KB を見るので、モデルが呼ばれるのは、まだ知られていない主張に限られます。

## 世界照合に使うモデル

世界照合は、**設定** → **AI** → **モデルの割り当て** の **軽い処理のモデル** で、いつも動きます。専用の選択欄はありません。軽い処理で足りるためです。測定では、ローカルの 30B 級のモデルが、上位のクラウドのモデルと同じ点でした。

モデルの登録やほかの割り当てについては、[AI のセットアップ](/ja/ai-setup)を参照してください。

## 再照合と verdict の削除 <Badge type="tip" text="v0.13.5 (2026-06-03) で追加" />

- **再照合**: もう一度 **世界照合** を押します。新しい結果が、古いものを置き換えます。
- **削除**: 項目下部の **世界照合 詳細** セクションで **照合結果を消す** を押すと、その項目に保存された verdict と出典が消えます。間違った判定や壊れたリンクが残ってしまったときに使います。一覧では、行を選んで件数付きの **照合を消す (n)** を押すと、まとめて消せます。

::: tip
手で消した項目は、自動照合が意図的に飛ばします。消す操作は、「これを自動で付け直さないでほしい」という合図になります。新しい verdict が欲しくなったら、自分で **世界照合** を押してください。
:::

## AI の回答に渡す範囲 <Badge type="tip" text="v0.16.8 (2026-07-02) で追加" />

AI に質問するときにも、これとつながった仕組みがあります。AI チャットパネルと `⌘K` Composer にある **渡す範囲** チップで、回答が何を根拠にするかを選びます。

- **外部参照**: Web 検索を必須にします。
- **内部参照**: 引用したものと、蓄積した知識の横断検索を使います。
- **ノート内参照**: このノートで引用したものだけを使います。既定です。

[ノートを開かずに話す](/ja/ai-chat-and-ask#ノートを開かずに話す)チャットにも同じチップがあります。こちらは **外部参照** と **内部参照** の 2 つです。詳しい内訳と、**外部参照** が Web に届くために必要なものは、[チャットと Ask (⌘K / Ctrl+K)](/ja/ai-chat-and-ask#choosing-what-grounds-the-answer)を参照してください。

## 照合データを管理する

**設定** → **照合データ** は、世界照合が突き合わせる知識ベースの中身を見たり、間引いたりする場所です。このタブは、**世界照合を使う** がオンのときだけ表示されます。最初は空で、照合を実行するほど育ちます。

![設定の照合データタブ。キャッシュされた KB エントリが verdict のフィルタとともに並んでいる](/screenshots/grounding-data-tab.png)

- ヘッダーにエントリの件数が出ます。verdict のフィルタチップや、**KB を検索...** の欄で、一覧を絞れます。
- 各エントリにはバッジが付きます。**seed** は、アプリに同梱された、手作業で整えたエントリです（画面からは削除できません）。**model** は、モデルの判定からたまったエントリです。バッジにカーソルを合わせると、どのモデルが作ったかが分かります。
- 個別のキャッシュのエントリは、ゴミ箱ボタンで削除できます。件数付きの **沈殿エントリを一括削除 (n)** を押すと、モデルの判定から作られたキャッシュのエントリをまとめて消せます。どちらの場合も、seed のエントリは残ります。

エントリを削除しても、影響するのは以後の照合だけです。もう信用できない判定を取り除き、次の **世界照合** で、新しい根拠から判定し直させるための操作です。
