# 設定

Graphium の設定はすべて 1 つのモーダルに入っています。サイドバー下部の **設定** をクリックして開きます。モーダルには 8 つのタブ — **表示・言語**、**ストレージ**、**共有**、**AI**、**照合データ**、**ナレッジ管理**、**使用量**、**アプリ情報** — があり、セットアップの順に並んでいます。初回の設定は、上から下・左から右に読み進めれば足ります。このページは各タブのマップです。ワークフロー全体は、各セクションからリンクした詳細ページで説明しています。

![AI タブを開いた設定モーダル](/screenshots/settings-ai-tab.png)

::: info 環境による違い
一部のグループは特定の環境にだけ現れます。フォルダの選択、共有、モバイルからの受け取り、更新の確認には[デスクトップアプリ](/ja/desktop-app)が必要です。該当するものは、下の各表に注記しています。
:::

## 表示・言語

Graphium の見た目と読みやすさ。

| グループ | 何ができるか |
|---|---|
| **言語** | UI を **English**・**日本語**・**한국어**（韓国語）で切り替えます <Badge type="tip" text="韓国語は v0.119.0 (2026-11-05) で追加" />。AI が書く文章（知識ページ・要約・音声ノート・チャットの返答）もこの言語に従います <Badge type="tip" text="韓国語の AI 出力は v0.120.0 (2026-11-05) で追加" />。 |
| **読みやすさ（フォント）** | ラテン文字と日本語のフォントを独立に設定します。ラテン文字フォントは英数字に、日本語フォントはひらがな・カタカナ・漢字に適用されます。 |
| **画面の大きさ** <Badge type="tip" text="v0.84.0 (2026-09-30) で追加" /> | ウィンドウ全体を小さく・大きくします。[デスクトップアプリ](/ja/desktop-app)では 50% から 150% までの倍率を選べ、選んだ時点で反映されます（倍率は覚えています）。ブラウザ版ではブラウザ自身の拡大縮小を案内するだけです。 |
| **新しいノートを A4 の幅で始める** <Badge type="tip" text="v0.85.1 (2026-10-01) で追加" /> | オンにすると、自分で始める新しいノートが [A4 の幅](/ja/notes-and-editor#a4-width)で始まります。効くのは、白紙のノート（サイドバーの新規ノート・フォルダの中の新規ノート・@ メンションから作るノート）、テンプレートから作るノート、取り込んだノート（Word・Markdown・URL・PDF）、計画の表の行から作るノートです。テンプレートが自分の幅を持っているときはそれに従います。ほかのノートから作ったノートは元のノートの幅に、共有から取り込んだノートは共有した人の設定に従い、既存のノートも変わりません。初めはオフで、**保存** で確定し、デスクトップの幅のときだけ表示されます。 |
| **これまでのノートも A4 にする** / **A4 のノートをすべて標準に戻す** <Badge type="tip" text="v0.85.1 (2026-10-01) で追加" /> | すぐ上の設定の下に並ぶ 2 つのボタンで、デスクトップの幅のときだけ表示されます。押すと確認が出て、そのあと自分のノートの幅を 1 件ずつ書き換えます。進み具合（たとえば 120 / 300 件）と **止める** ボタンが出て、止めたときはもう一度押すと続きから進みます。書き換えるのは幅だけで、一覧に出る更新日時とその並び・ノートに記録された履歴・ほかの内容は変わりません。幅いっぱいにしてあるノートとゴミ箱のノートはそのままです（アーカイブしたノートは含みます）。開いているノートはその場で切り替わります。上のボタンは A4 でないノートを A4 にし、下のボタンは A4 のノートすべてから A4 を外して標準の幅に戻します。 |
| **来歴ラベルの表記** | アプリ全体で表示される来歴ラベルの名前を変更します。[ラベルと来歴](/ja/labels-and-provenance)を参照。 |

ラテン文字フォントの選択肢は **デフォルト（Inter）**、**Atkinson Next + 数字 Inter（dyslexia 配慮）**、**Atkinson Next 単体（数字もスラッシュ 0）**、**Lexend（読み速度最適化 / NASA 共同研究）** です。日本語フォントの選択肢は **デフォルト（OS のシステムフォント）**、**Zen Kaku Gothic New（本文向き、字間ゆったり）**、**BIZ UDPGothic（UD 配慮 / モリサワ × 政府）** です。

フォントの隣に **読みやすさ（色）** <Badge type="tip" text="v0.34.0 (2026-08-13) で追加" /> があります（「文字と紙の色をプリセットから選べます」）。選択肢は **デフォルト（緑がかった紙）**、**高コントラスト（文字を濃く）** — 本文のコントラスト比が約 14:1 から約 18:1 になります — そして背景の緑みをなくす **白い紙（背景を純白に）** です。

![先頭を表示した表示・言語タブ。Language（English・日本語・한국어）、画面の大きさ（ショートカット付き）、ノートの幅（新しいノートを A4 の幅で始める と 2 つの一括切り替えボタン）、読みやすさ（フォント）が並び、読みやすさ（色）が見え始めている](/screenshots/settings-display-tab.png)

**来歴ラベルの表記**（既定で畳まれているグループです。見出し横の **くわしく** を押すと長い説明が開きます）では 5 つのラベルの名前を変えられます。既定は **ステップ**、**インプット**、**ツール**、**パラメータ**、**アウトプット** で、各行には対応する PROV-DM の役割（`prov:Activity`、`prov:used`、`prov:Entity`、`prov:wasGeneratedBy`）が表示されます。欄を空にすると既定の名前が使われます。**デフォルトに戻す** を押せば、カスタム名を一度に全部消せます。

## ストレージ

ノートがどこに置かれ、端末間をどう移動するか。詳細は[保存と同期](/ja/storage-and-sync)にあります。上の 2 つは畳まれていません。残りは既定で畳まれた 2 つのグループに入っていて、必要なときに開きます。人と共有するための設定は、すぐ次の[**共有**](#sharing)タブにあります。

| グループ | 何ができるか |
|---|---|
| **ノートの置き場所** | デスクトップ版のみ — ノート・メディア・ナレッジを保存するフォルダを変更します（Dropbox / Drive / OneDrive の同期フォルダを指定すれば、OAuth なしで同期できます）。 |
| **書き出しとバックアップ** | 全ノートを Markdown ファイルとして、または全ノート・ナレッジ・スキルドキュメントを含む生データの JSON バックアップとしてダウンロードします。 |
| **スマホやブラウザから送る** | 既定で畳まれているグループで、自分のスマホやブラウザからこの Graphium へ取り込む口が入っています。**スマホから送る** <Badge type="tip" text="v0.23.1 (2026-07-29) で追加" />（スマホでの記録のデスクトップ側です。スマホで Graphium を開く QR コード、記録を受け取る同期フォルダを指定する **受信フォルダ**、そして **処理済みファイルを `_imported/` に残す** のオプションがあります。[スマホでの記録](/ja/mobile)を参照）と **Web クリップ**（ブラウザで読んだところを Graphium に拾う Chrome 拡張機能のペアリングコード。**コピー** と **コードを作り直す** があります。[Web クリップ](/ja/web-clip)を参照）です。 |
| **詳しい設定** | 既定で畳まれているグループで、**検索インデックス** <Badge type="tip" text="v0.39.0 (2026-08-17) で追加" /> が入っています。ノート本文・ナレッジ・素材のテキスト（画像の OCR、URL の抜粋、PDF と Word の本文）を全文検索するための、この端末の中の索引です。`⌘K`（Windows/Linux は `Ctrl+K`）の検索と AI チャットの横断検索が使います。索引済みのソース数と断片数が表示され、検索結果がおかしいときは **索引を作り直す** で消して作り直せます。**中身を見る** で索引そのものを開けます。**断片** は索引済みのソース一覧で、開くと「どんな断片に切られたか」と「各断片がどんな語に分割されて索引されたか」（日本語の切れ目）が見え、語を打つと試し検索になります。**語彙** は索引に入っている語の一覧（数字はその語を含む断片の数）で、絞り込めます。ノートのデータには書き込みません。 |

::: warning
**ノートの置き場所** を変えても、既存のノートは自動では移動しません。先に旧フォルダの中身を新しいフォルダへコピーしてから、Graphium を再起動してください。
:::

## 共有 <Badge type="tip" text="v0.122.0 (2026-11-06) で追加" /> {#sharing}

チームメイトに対してあなたが誰なのか、どこで共有するか。デスクトップ版のみです。詳細は[保存と同期](/ja/storage-and-sync#sharing-notes-with-your-team)にあります。以前はストレージタブの畳まれたグループに入っていた設定が、展開しなくても見えるように並んでいます。

| グループ | 何ができるか |
|---|---|
| **あなたの名前** | 表示名とメール。共有ノートと来歴エントリの author として使われます。 |
| **共有フォルダ** | 公開したノートが置かれる **フォルダの場所**（研究室の NAS や同期フォルダなど、チーム全員が届く場所）を指定します。共有ノートのメディアの実体は、Graphium がその中に作る `_blobs` フォルダに置かれます。別の場所にしたいときは、行の詳しい設定の **大きなファイルの置き場（画像・PDF など）** で選べます。共有フォルダは 1 件 1 行で、状態・名前・場所・中身の件数が並びます。行を押すと詳しい設定が開き、**接続を確かめる** でそのフォルダに往復の確認ができます。**共有フォルダを追加** で、組織全体と部署のように読める人ごとのフォルダを増やせます。それぞれに名前と大きなファイルの置き場を持ち、1 件目が新しく共有するものの置き場（既定の共有先）です（[くわしく](/ja/storage-and-sync#several-shared-folders)）。 |
| **共有フォルダの中身を ⌘K と AI チャットの対象に含める** | スイッチです。共有フォルダを設定すると既定でオンになります。共有フォルダのエントリが `⌘K`（Windows/Linux は `Ctrl+K`）の検索と AI チャットの横断検索に現れます。オフにすると、どちらも自分のノートだけが対象になります。 |
| **共有に AI チャットと編集来歴を含める** | スイッチです。既定はオフです。オンにすると、共有するたびにノートの AI チャットと編集来歴も一緒に渡ります。 |

## AI

AI 関連のすべて。まず状態表示、次にモデルの登録、任意の追加設定と続き、最後にあまり触らない設定をまとめてあります。大見出しはどれも見出しを押して開閉でき、閉じていても今の設定が見出しの下に 1 行で出ます。最初から開いているのは **モデルの割り当て** と **外部ツールとの接続（MCP）** だけです（開閉はブラウザが覚えます）。手順の全体は [AI のセットアップ](/ja/ai-setup)にあります。

| グループ | 何ができるか |
|---|---|
| 状態表示 | モデルが 1 つも登録されていなければ **AI はまだ使えません** と **AI を登録する** の近道が、登録済みなら **AI が使えます**（使用中のモデル名つき）が表示されます。 |
| **登録済みモデル** | モデルを追加・管理します — Anthropic、OpenAI、Google Gemini、OpenAI 互換のエンドポイント、ChatGPT のプラン、GitHub Copilot のサブスクリプション。モデルごとの単価も任意で設定できます。モデルを 1 つ以上登録すると、一覧は名前を並べた 1 行に畳まれます。見出しを押すと開きます。 |
| **モデルの割り当て** | モデル一覧のすぐ下にあり、最初から開いています（閉じると 3 段のいまのモデルが 1 行で出ます）: 仕事の難しさ別の 3 段 — **軽い処理のモデル**（チャット・点検・出典照合などの軽い処理。ほかの段を空欄にするとこれを使います）、**標準の処理のモデル**（ナレッジ化・翻訳・トピックの整理）、**高度な処理のモデル**（手順ノート・計画・洞察・清書） — と、**埋め込みモデル**（**埋め込みテスト** で確認できます）。標準と高度は見出しのスイッチでオフにでき、オフの段の機能は画面に出なくなります（[段を使う・使わない](/ja/ai-setup#段を使う使わない)）。世界照合はいつも軽い処理のモデルで動きます。チャットは、空欄なら軽い処理のモデルで答えます。**チャット** の束の **チャットのモデル** で、別のモデルを選べます。それぞれの **くわしく** に、どの機能が使うかと、空欄のときにどのモデルへ回るかを書いています。 |
| **このパソコンで埋め込み** <Badge type="tip" text="v0.99.0 (2026-10-27) で追加" /> | デスクトップ版だけ。**埋め込みモデル**はこのパソコンで動かせます。空欄のままなら **bge-m3** が既定になり（すでに API のモデルで埋め込みを作っていた人はそのモデルのまま）、**このパソコンで → bge-m3（おすすめ）** か **multilingual-e5-small（軽め）** を自分で選ぶこともできます。モデルは 1 度だけ取得します（587 MB / 136 MB）——既定が最初に要るときに自動で始まるか、**取得** ボタンで。終わるまではテキスト一致で探します。文はパソコンの外に出ず、Anthropic や Copilot など埋め込みに対応しない接続先でも意味の近さで検索できます。 |
| **チャット** | モデルの割り当てのすぐ下にある、チャットの設定です。畳むと、1 行に「チャットのモデル」と「じっくり調べてから答える」のいまの状態が出ます: |
| &nbsp;&nbsp;**チャットのモデル** <Badge type="tip" text="v0.129.8 (2026-11-10) で追加" /> | チャットの回答に使うモデルを選びます。ノートの横のチャット、ノートを開かないチャット、`⌘K`（Windows/Linux は `Ctrl+K`）の質問と執筆、回答をページに残すときの書き直しが、選んだモデルで動きます。**じっくり調べてから答える** がオンのときの回答も、ここで選んだモデルです。空欄（**軽い処理のモデルと同じ**）なら、ふつうの回答は軽い処理のモデル、じっくり調べるときは高度な処理のモデルで答えます。チャットとノートの題付けは、いつも軽い処理のモデルです。一緒に考えたり、案を比べたりする会話には、賢いモデルが向いています。高度な処理をオフにしていても、この欄は出ます。 |
| &nbsp;&nbsp;**じっくり調べてから答える** <Badge type="tip" text="v0.93.0 (2026-10-21) で追加" /> | 既定はオフです。オンにすると、**内部参照** または **外部参照** のチャット（とノートを開いていないチャット）で、AI が言い換えてノート・トピック・知見・素材をもう一度探したり、断片では足りないページを全文で読んだり、記録した構造（材料や道具を使ったノート・ノートの手順・来歴）をたどったりします <Badge type="tip" text="v0.116.0 (2026-11-04) で追加" />。応答は少し遅くなり、AI の利用量も増えます。読むだけで、何も書き換えません。オンのあいだは、チャットのモデルを選んでいればそのモデル、空欄ならモデルの割り当ての高度な処理のモデルで答えます。[じっくり調べてから答えてもらう](/ja/ai-chat-and-ask#letting-the-ai-search-again)を参照。 |
| **音声ノート** | デスクトップ版だけ。モデルの割り当てとチャットの下にあり、モデルを登録する前から出ます（文字起こしはこのパソコンの中で動くため）。音声モデル・言語・よく使う用語・**録音中に文字起こしを進める**・**清書と要約に使う AI モデル** を設定します。[音声ノート](/ja/voice-notes#settings)を参照。 |
| **ナレッジ** | 取り込みと点検の設定です: |
| &nbsp;&nbsp;**資料の要約ページを作る** <Badge type="tip" text="v0.89.14 (2026-10-20) で追加" /> | 全員が既定オフ。オンにすると、PDF・URL の取り込みで、その資料の[要約](/ja/knowledge-layer)ページを 1 枚書きます（資料 1 件につき AI 呼び出しが 1 回増えます）。要約はトピックと同じ決まり（1 文ごとに出典）で書かれ、出典照合にかけられます。同じ資料を取り込み直すと既存の要約を書き直します。ノートと Word には作りません。 |
| &nbsp;&nbsp;**自動点検を AI 解析（フル）にする** <Badge type="tip" text="v0.79.0 (2026-09-18) で追加" /> | 取り込み直後・起動時 24h ごとに自動で走る点検を、機械判定だけのクイックから AI 解析まで行うフルへ切り替えます（既定はオフ。オンにした人だけ、自動の点検で AI を呼びます）。オンにしても、自動の点検が直すことはありません。直すのは、**おまかせで整える** を押したときか、自分で選んだときだけです。[ログと手入れ](/ja/knowledge-layer#ログと手入れ)を参照。 |
| **外部ツールとの接続（MCP）** | 最初から開いているグループで、**MCP サーバー** <Badge type="tip" text="v0.13.6 (2026-06-04) で追加" /> が入っています。外部のツールサーバーを直接つなぎます — 確かめ済みの接続先（Tavily など）を選ぶか公式の MCP Registry を探してキーを貼るか、**詳しい設定** でサーバーの README から **JSON を貼る**、**手動入力** で 1 件ずつ設定、または **レジストリから** 候補を引く（[くわしく](/ja/ai-setup#mcp-サーバー)）。 畳んだ行に、登録しているサーバーの数が出ます。 |
| **外の AI からノートを使う** | 既定で畳まれているグループで、MCP のグループと先行公開の機能のあいだにあります。デスクトップアプリのみ。Claude Desktop・Claude Code・Codex に Graphium を 1 回で登録し（**登録する**、2 回目以降は **登録し直す**）、会話の中でノートを探したり保存したりできるようにします。[デスクトップ版から登録する](/ja/mcp-server#register-from-the-app)を参照。 |
| **先行公開の機能** <Badge type="tip" text="v0.92.0 (2026-10-20) で追加" /> | いちばん下の、既定で畳まれているグループです。どれかをオンにしていると、畳んだ行に名前が出ます（例: **オンにしているもの: 世界照合・知見・洞察**）。中身は次のとおりです: |
| &nbsp;&nbsp;**世界照合を使う** <Badge type="tip" text="v0.75.0 (2026-09-16) で追加" /> | 世界照合のマスタースイッチ（初めて使うときはオフ、以前から使っている場合はオン）。オフにすると、照合のボタンと列がどこからも隠れます。ノートに保存済みの照合結果は残ります。 |
| &nbsp;&nbsp;**世界照合** | **自動で世界照合する** をオンにします（照合そのものはいつも **軽い処理のモデル** で動き、選択欄はありません）。[世界照合](/ja/ai-grounding)を参照。 |
| &nbsp;&nbsp;**自動で出典照合する** | **世界照合** のすぐ後の、**出典照合** の見出しの下にあります。オンにすると、新しく作られた・更新された知見とトピックを、出典 1 件ごとに AI を呼びながらバックグラウンドで 1 件ずつ照合します（既定オフ）。[自動で出典照合する](/ja/ai-grounding#自動で出典照合する)を参照。 |
| &nbsp;&nbsp;**知見を使う** <Badge type="tip" text="v0.78.0 (2026-09-17) で追加" /> | 知見のマスタースイッチ（初めて使うときはオフ、以前から使っている場合はオン）。トピック（資料から直接作られる）は常にオンで、知見は Graphium 独自の拡張で、ノートや資料に含まれる命題（「Y のとき X になる」など）を、1 つの命題につき 1 件として、あるだけ取り出します。実験固有の詳細は除き、他の文脈でも使える形で書きます。オフにすると取り込みで知見の抽出をしなくなります（トピック段は引き続き走ります）。作成済みの知見は残り、1 件以上あれば引き続き表示されます。知見をオフにすると洞察も自動でオフになります（洞察は知見から作るため）。 |
| &nbsp;&nbsp;**洞察を使う** <Badge type="tip" text="v0.75.0 (2026-09-16) で追加" /> | 洞察のマスタースイッチ（初めて使うときはオフ、以前から使っている場合はオン。**知見を使う**がオフの間は無効化）。オフにすると、サイドバーと一覧から洞察が隠れます。作成済みの洞察は残ります。 |
| &nbsp;&nbsp;**洞察の発見** <Badge type="tip" text="v0.45.0 (2026-08-25) で追加" /> | 洞察は **高度な処理のモデル** で動きます。その力量を **洞察のテスト** で確認できます。続いて **取り込み時のスキャン回数（上限）** — ノートをナレッジに取り込むたび、洞察のスキャンに使ってよい LLM 呼び出し回数の上限です（既定 3。0 にすると取り込み時には探しません）。[ナレッジ層](/ja/knowledge-layer)を参照。 |
| &nbsp;&nbsp;**Asterism と連携する** | 知見を Asterism（知識グラフ）に渡し、規則に反する観察を見つけられるようにします。既定はオフです。 |

ブラウザ版にはバックエンドがないため、このタブにはアップグレードの案内が表示されます。MCP サーバーには 2 種類あり、**ローカル**（Graphium が起動・管理する。デスクトップアプリのみ）と **リモート**（起動済みのサーバーに URL で接続する）です。

## 照合データ

[世界照合](/ja/ai-grounding)が突き合わせる知識ベースのブラウザです。最初は空で、放っておいても自然に育ちます。照合が KB を外れるたび、モデルの判定がここにキャッシュされて再利用されるので、照合は使うほど速く・安くなります。

| グループ | 何ができるか |
|---|---|
| エントリ一覧 | KB のエントリを検索・絞り込みします。各エントリには **seed** バッジ（手キュレーションの同梱）か **model** バッジ（モデル判定からのキャッシュ）が付きます。 |
| 個別の削除 | キャッシュエントリを 1 件ずつ削除します。seed エントリは UI からは削除できません。 |
| **沈殿エントリを一括削除** | モデル由来のキャッシュエントリをまとめて消し、同梱の seed セットは残します。 |

## ナレッジ管理 <Badge type="tip" text="v0.81.1 (2026-09-18) で追加" />

編集可能な**ナレッジスキーマ**はこのタブではなく、サイドバーの**スキル**一覧にあります。これは1件だけの組み込み文書であり、ナレッジ件数、検索、グラフには含まれません。初回作成時だけ、その時点の UI 言語に合わせた既定本文が保存されます。その後に UI 言語を変えても自動翻訳・上書きされません。意図して別言語の同梱既定本文へ置換するときは、ナレッジスキーマを開いて確認付きの言語切替を使います。保存した規約は以後のトピック・問答（Q&A）・知見の生成へ適用され、編集、言語切替、リセットで既存ページが自動再生成されることはありません。

[ナレッジ層](/ja/knowledge-layer)のメンテナンス作業です。いずれも LLM を呼ぶので、各ジョブは実行前に確認を求め、トークンのコストは[使用量](#使用量)タブに記録されます。

| グループ | 何ができるか |
|---|---|
| **接続状態** | バックエンドの各コンポーネントの状態を表示します。デスクトップアプリでは **バックエンドを再起動** ボタンも出ます。 |
| **全ナレッジの埋め込みを作り直す** | AI チャットの引用検索を支える埋め込みを作り直します。引用の検索が動かなくなったときに使います。索引に今選んでいる埋め込みモデルのベクトルが残っているかも（全件走査せず）軽く確認し、モデルが変わって作り直しが要りそうなときはここに 1 行の案内を出します——費用が API キーにかかるため、自動では作り直しません。 |
| **トピックを整理** <Badge type="tip" text="v0.75.0 (2026-09-16) で追加" /> | 同じ概念を指す既存のトピックどうし（表記ゆれ・助詞の有無・細かすぎる事例単位のトピックなど）を統合し、ページをまとめます。トピックページどうしの統合だけを行い、知見をトピックへ割り当てることはしません（2026-09-17 変更）。統合されたトピックは完全削除ではなくゴミ箱へ送られます。 |
| **トピックに種類を付ける** <Badge type="tip" text="v0.89.15 (2026-10-20) で追加" /> | [種類](/ja/knowledge-layer#topic-types)の無いトピックがあるときだけ出ます。未分類のトピックのタイトルと定義の 1 文を 50 件ずつ AI に渡し（呼び出し回数は実行前に表示）、種類（概念・物質・材料・手法・装置・人・組織・場所）を書き戻します。本文は変えません。種類はナレッジ一覧の種類列と、全体グラフの「トピック: …」の表示切替に使います。各トピックの種類はページのバナーで直せます。 |
| **ナレッジの一括再生成** | プロンプトやモデルを変えたあと、既存のナレッジページを作り直します。**対象の種類** のフィルタ（**トピック** / **知見** / **洞察** — 要約は新規生成を停止済みのため対象外）、任意のモデル指定、キャンセル、**失敗したナレッジだけ再試行** に対応しています。トピックは資料から作り直すため、トピックを含む一括実行はページ数ではなく資料数ぶん AI を呼びます — 対象件数の横に AI 呼び出し回数を出し、トピックを含むときは実行前に確認します。 |
| **知見をまたぐ洞察を発見** | 知見を似たもの同士のクラスタに分けて順にスキャンし、知見の中にある関係の型を洞察として取り出します（同じ型の知見は 1 件にまとめます）。すべての知見が一度は視野に入るまで回り、必要な LLM 呼び出し回数は手持ちの知見から計算して実行前に表示されます。途中で停止もできます。 |

![設定の Knowledge タブ。Connection Status、Discover Insights from Claims、Re-embed all Knowledge、Organize topics、Bulk regenerate Knowledge（対象の種類・モデル選択・Run bulk regenerate）のカードが縦に並んでいる。](/screenshots/settings-knowledge-tab.png)

## 使用量

<Badge type="tip" text="v0.12.0 (2026-05-28) で追加" />

**AI 使用量** のダッシュボードです。AI 機能ごとのトークン消費量が見えるので、いまの構成にどれだけかかっているかが常に分かります。

| グループ | 何ができるか |
|---|---|
| 期間 | **時系列のトークン** チャートの粒度を **日**・**月**・**年** で切り替えます。 |
| 合計 | **合計トークン** と **想定コスト**。想定コストは [AI](#ai) タブで設定したモデルごとの単価から計算されます。 |
| **機能別の内訳** | Graphium のどの部分がトークンを使ったのかを、機能ごとに分解します。 |
| 通貨 | コストを USD か JPY で表示します。**1 USD = ¥** の為替レートは編集できます。 |
| **コストを再計算** | 直近 90 日分のコストを、現在のモデル単価で計算し直します。 |

![設定の Usage タブ。Month を選び、Total tokens と Estimated cost、高さの違う月ごとの Tokens over time の棒グラフ、全機能に費用が付いた By feature の内訳、USD/JPY の切り替えと 1 USD = ¥ のレート、Recalculate cost ボタンが見える。](/screenshots/settings-usage-tab.png)

サブスクリプションのモデルは別扱いで、**Subscription（従量課金なし）** と表示されます。トークン単位の課金がないためです。使用量の記録にはデスクトップアプリが必要です。
