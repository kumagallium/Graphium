# 設定

Graphium の設定は、すべて 1 つのモーダルにまとまっています。サイドバー下部の **設定** をクリックして開きます。

モーダルには 8 つのタブがあり、セットアップの順に並んでいます。

- **表示・言語**
- **ストレージ**
- **共有**
- **AI**
- **照合データ**
- **ナレッジ管理**
- **使用量**
- **アプリ情報**

初回の設定は、上から下、左から右に読み進めれば足ります。このページは各タブの案内です。操作の流れ全体は、各セクションからリンクした詳細ページで説明しています。

![AI タブを開いた設定モーダル](/screenshots/settings-ai-tab.png)

::: info 環境による違い
一部のグループは特定の環境にだけ現れます。フォルダの選択、共有、モバイルからの受け取り、更新の確認には[デスクトップアプリ](/ja/desktop-app)が必要です。該当するものは、下の各表に注記しています。
:::

## 表示・言語

Graphium の見た目と読みやすさを整えるタブです。

| グループ | 何ができるか |
|---|---|
| **言語** | 画面の言語を **English**・**日本語**・**한국어**（韓国語）から選びます <Badge type="tip" text="韓国語は v0.119.0 (2026-11-05) で追加" />。AI が書く文章（知識ページ・要約・音声ノート・チャットの返答）も、この言語で書かれます <Badge type="tip" text="韓国語の AI 出力は v0.120.0 (2026-11-05) で追加" />。 |
| **読みやすさ（フォント）** | ラテン文字と日本語のフォントを、別々に設定します。ラテン文字フォントは英数字に、日本語フォントはひらがな・カタカナ・漢字に使われます。 |
| **画面の大きさ** <Badge type="tip" text="v0.84.0 (2026-09-30) で追加" /> | ウィンドウ全体を小さくしたり大きくしたりします。[デスクトップアプリ](/ja/desktop-app)では 50% から 150% までの倍率を選べます。選んだ時点で反映され、倍率は覚えています。ブラウザ版では、ブラウザ自身の拡大縮小を案内するだけです。 |
| **新しいノートを A4 の幅で始める** <Badge type="tip" text="v0.85.1 (2026-10-01) で追加" /> | オンにすると、自分で始める新しいノートが [A4 の幅](/ja/notes-and-editor#a4-width)で始まります。初めはオフです。**保存** で確定し、デスクトップの幅のときだけ表示されます。<br>効くノート: 白紙のノート（サイドバーの新規ノート・フォルダの中の新規ノート・@ メンションから作るノート）、テンプレートから作るノート、取り込んだノート（Word・Markdown・URL・PDF）、計画の表の行から作るノート。<br>効かないノート: テンプレートが自分の幅を持っているときは、その幅に従います。ほかのノートから作ったノートは元のノートの幅に、共有から取り込んだノートは共有した人の設定に従います。既存のノートも変わりません。 |
| **これまでのノートも A4 にする** / **A4 のノートをすべて標準に戻す** <Badge type="tip" text="v0.85.1 (2026-10-01) で追加" /> | すぐ上の設定の下に並ぶ 2 つのボタンで、デスクトップの幅のときだけ表示されます。上のボタンは A4 でないノートを A4 にします。下のボタンは、A4 のノートすべてから A4 を外して標準の幅に戻します。<br>押すと確認が出て、そのあと自分のノートの幅を 1 件ずつ書き換えます。進み具合（たとえば 120 / 300 件）と **止める** ボタンが出ます。止めたときは、もう一度押すと続きから進みます。<br>書き換えるのは幅だけです。一覧に出る更新日時とその並び、ノートに記録された履歴、ほかの内容は変わりません。幅いっぱいにしてあるノートとゴミ箱のノートはそのままです。アーカイブしたノートは、書き換えの対象に含みます。開いているノートは、その場で切り替わります。 |
| **来歴ラベルの表記** | アプリ全体に表示される来歴ラベルの名前を変えます。[ラベルと来歴](/ja/labels-and-provenance)を参照。 |

ラテン文字フォントの選択肢は次のとおりです。

- **デフォルト（Inter）**
- **Atkinson Next + 数字 Inter（dyslexia 配慮）**
- **Atkinson Next 単体（数字もスラッシュ 0）**
- **Lexend（読み速度最適化 / NASA 共同研究）**

日本語フォントの選択肢は次のとおりです。

- **デフォルト（OS のシステムフォント）**
- **Zen Kaku Gothic New（本文向き、字間ゆったり）**
- **BIZ UDPGothic（UD 配慮 / モリサワ × 政府）**

フォントの隣に **読みやすさ（色）** <Badge type="tip" text="v0.34.0 (2026-08-13) で追加" /> があります（「文字と紙の色をプリセットから選べます」）。選択肢は次の 3 つです。

- **デフォルト（緑がかった紙）**
- **高コントラスト（文字を濃く）**: 本文のコントラスト比が約 14:1 から約 18:1 になります。
- **白い紙（背景を純白に）**: 背景の緑みをなくします。

![先頭を表示した表示・言語タブ。Language（English・日本語・한국어）、画面の大きさ（ショートカット付き）、ノートの幅（新しいノートを A4 の幅で始める と 2 つの一括切り替えボタン）、読みやすさ（フォント）が並び、読みやすさ（色）が見え始めている](/screenshots/settings-display-tab.png)

**来歴ラベルの表記** は、既定で畳まれているグループです。見出し横の **くわしく** を押すと、長い説明が開きます。ここでは 5 つのラベルの名前を変えられます。

- 既定の名前は **ステップ**、**インプット**、**ツール**、**パラメータ**、**アウトプット** です。
- 各行には、対応する PROV-DM の役割（`prov:Activity`、`prov:used`、`prov:Entity`、`prov:wasGeneratedBy`）が表示されます。
- 欄を空にすると、既定の名前が使われます。
- **デフォルトに戻す** を押すと、自分で付けた名前を一度に全部消せます。

## ストレージ

ノートをどこに置くか、端末のあいだでどう受け渡すかを決めるタブです。詳しくは[保存と同期](/ja/storage-and-sync)にあります。上の 2 つのグループは畳まれていません。残りの 2 つは既定で畳まれているので、必要なときに開きます。人と共有するための設定は、すぐ次の[**共有**](#sharing)タブにあります。

| グループ | 何ができるか |
|---|---|
| **ノートの置き場所** | デスクトップ版のみ。ノート・メディア・ナレッジを保存するフォルダを変更します。Dropbox / Drive / OneDrive の同期フォルダを指定すれば、OAuth なしで同期できます。 |
| **書き出しとバックアップ** | 全ノートを Markdown ファイルとしてダウンロードします。または、全ノート・ナレッジ・スキルドキュメントを含む生データを、JSON のバックアップとしてダウンロードします。 |
| **スマホやブラウザから送る** | 既定で畳まれているグループです。自分のスマホやブラウザから、この Graphium へ取り込む入口が入っています。<br>**スマホから送る** <Badge type="tip" text="v0.23.1 (2026-07-29) で追加" />: スマホでの記録のデスクトップ側です。スマホで Graphium を開く QR コード、記録を受け取る同期フォルダを指定する **受信フォルダ**、**処理済みファイルを `_imported/` に残す** オプションがあります。[スマホでの記録](/ja/mobile)を参照。<br>**Web クリップ**: ブラウザで読んだ内容を Graphium に取り込む Chrome 拡張機能の、ペアリングコードです。**コピー** と **コードを作り直す** があります。[Web クリップ](/ja/web-clip)を参照。 |
| **詳しい設定** | 既定で畳まれているグループです。**検索インデックス** <Badge type="tip" text="v0.39.0 (2026-08-17) で追加" /> が入っています。<br>検索インデックスは、ノート本文・ナレッジ・素材のテキスト（画像の OCR、URL の抜粋、PDF と Word の本文）を全文検索するための、この端末の中の索引です。`⌘K`（Windows/Linux は `Ctrl+K`）の検索と、AI チャットの横断検索が使います。ノートのデータには書き込みません。<br>索引済みのソース数と断片数が表示されます。検索結果がおかしいときは、**索引を作り直す** で消して作り直せます。**中身を見る** で、索引そのものを開けます。<br>**断片** は、索引済みのソースの一覧です。開くと、どんな断片に切られたかと、各断片がどんな語に分割されて索引されたか（日本語の切れ目）が見えます。語を打つと、試しに検索できます。<br>**語彙** は、索引に入っている語の一覧です。数字は、その語を含む断片の数です。語で絞り込めます。 |

::: warning
**ノートの置き場所** を変えても、既存のノートは自動では移動しません。先に旧フォルダの中身を新しいフォルダへコピーしてから、Graphium を再起動してください。
:::

## 共有 <Badge type="tip" text="v0.122.0 (2026-11-06) で追加" /> {#sharing}

チームメイトに自分が誰として見えるか、どこで共有するかを決めるタブです。デスクトップ版のみです。詳しくは[保存と同期](/ja/storage-and-sync#sharing-notes-with-your-team)にあります。以前はストレージタブの畳まれたグループに入っていた設定を、開かなくても見えるように並べています。

| グループ | 何ができるか |
|---|---|
| **あなたの名前** | 表示名とメールを設定します。共有ノートと来歴エントリの author として使われます。 |
| **共有フォルダ** | 公開したノートを置く **フォルダの場所** を指定します。研究室の NAS や同期フォルダなど、チーム全員が届く場所です。<br>共有ノートのメディアの実体は、Graphium がそのフォルダの中に作る `_blobs` フォルダに置かれます。別の場所にしたいときは、行の詳しい設定にある **大きなファイルの置き場（画像・PDF など）** で選べます。<br>共有フォルダは 1 件 1 行で、状態・名前・場所・中身の件数が並びます。行を押すと詳しい設定が開きます。**接続を確かめる** を押すと、そのフォルダと行き来できるかを確認できます。<br>**共有フォルダを追加** を押すと、組織全体用と部署用のように、読める人ごとのフォルダを増やせます。それぞれに名前と大きなファイルの置き場があり、1 件目が新しく共有するものの置き場（既定の共有先）です（[くわしく](/ja/storage-and-sync#several-shared-folders)）。 |
| **共有フォルダの中身を ⌘K と AI チャットの対象に含める** | スイッチです。共有フォルダを設定すると、既定でオンになります。共有フォルダのエントリが、`⌘K`（Windows/Linux は `Ctrl+K`）の検索と AI チャットの横断検索に出てきます。オフにすると、どちらも自分のノートだけが対象になります。 |
| **共有に AI チャットと編集来歴を含める** | スイッチです。既定はオフです。オンにすると、共有するたびに、ノートの AI チャットと編集来歴も一緒に渡ります。 |

## AI

AI に関する設定が、すべてここにあります。上から順に、状態表示、モデルの登録、任意の追加設定が並び、最後にあまり触らない設定がまとまっています。

大見出しはどれも、押すと開閉できます。閉じていても、今の設定が見出しの下に 1 行で出ます。最初から開いているのは **モデルの割り当て** と **外部ツールとの接続（MCP）** だけです。開閉の状態はブラウザが覚えます。手順の全体は [AI のセットアップ](/ja/ai-setup)にあります。

| グループ | 何ができるか |
|---|---|
| 状態表示 | モデルが 1 つも登録されていなければ、**AI はまだ使えません** と、**AI を登録する** への近道が出ます。登録済みなら、**AI が使えます** と、使用中のモデル名が出ます。 |
| **登録済みモデル** | モデルを追加・管理します。使えるのは、Anthropic、OpenAI、Google Gemini、OpenAI 互換のエンドポイント、GitHub Copilot のサブスクリプションです。モデルごとの単価も、任意で設定できます。モデルを 1 つ以上登録すると、一覧は名前を並べた 1 行に畳まれます。見出しを押すと開きます。 |
| **モデルの割り当て** | モデル一覧のすぐ下にあり、最初から開いています。閉じると、3 段それぞれのいまのモデルが 1 行で出ます。<br>仕事の難しさ別に 3 段あります。**軽い処理のモデル**（チャット・点検・出典照合などの軽い処理。ほかの段を空欄にすると、これを使います）、**標準の処理のモデル**（ナレッジ化・翻訳・トピックの整理）、**高度な処理のモデル**（手順ノート・計画・洞察・清書）です。ほかに **埋め込みモデル** があり、**埋め込みテスト** で確認できます。<br>標準と高度は、見出しのスイッチでオフにできます。オフにした段の機能は、画面に出なくなります（[段を使う・使わない](/ja/ai-setup#段を使う使わない)）。<br>世界照合は、いつも軽い処理のモデルで動きます。チャットは、空欄なら軽い処理のモデルで答えます。**チャット** のグループの **チャットのモデル** で、別のモデルを選べます。<br>それぞれの **くわしく** に、どの機能が使うかと、空欄のときにどのモデルを使うかが書いてあります。 |
| **このパソコンで埋め込み** <Badge type="tip" text="v0.99.0 (2026-10-27) で追加" /> | デスクトップ版だけ。**埋め込みモデル** を、このパソコンで動かせます。<br>空欄のままなら、**bge-m3** が既定になります。すでに API のモデルで埋め込みを作っていた人は、そのモデルのままです。**このパソコンで → bge-m3（おすすめ）** か **multilingual-e5-small（軽め）** を、自分で選ぶこともできます。<br>モデルは 1 度だけ取得します（587 MB / 136 MB）。既定のモデルが最初に必要になったときに自動で始まるか、**取得** ボタンで始めます。取得が終わるまでは、テキストの一致で探します。<br>文はパソコンの外に出ません。Anthropic や Copilot など、埋め込みに対応しない接続先を使っていても、意味の近さで検索できます。 |
| **チャット** | モデルの割り当てのすぐ下にある、チャットの設定です。畳むと、1 行に「チャットのモデル」と「じっくり調べてから答える」のいまの状態が出ます。次の 2 行が、その中身です。 |
| &nbsp;&nbsp;**チャットのモデル** <Badge type="tip" text="v0.129.8 (2026-11-10) で追加" /> | チャットの回答に使うモデルを選びます。選んだモデルで動くのは、ノートの横のチャット、ノートを開かないチャット、`⌘K`（Windows/Linux は `Ctrl+K`）の質問と執筆、回答をページに残すときの書き直しです。**じっくり調べてから答える** がオンのときの回答も、ここで選んだモデルで動きます。<br>空欄（**軽い処理のモデルと同じ**）なら、ふつうの回答は軽い処理のモデルで、じっくり調べるときは高度な処理のモデルで答えます。チャットとノートの題付けは、いつも軽い処理のモデルです。<br>一緒に考えたり、案を比べたりする会話には、賢いモデルが向いています。高度な処理をオフにしていても、この欄は出ます。 |
| &nbsp;&nbsp;**じっくり調べてから答える** <Badge type="tip" text="v0.93.0 (2026-10-21) で追加" /> | 既定はオフです。オンにすると、**内部参照** または **外部参照** のチャット（とノートを開いていないチャット）で、AI が次のことをします。<br>・言い換えて、ノート・トピック・知見・素材をもう一度探す<br>・断片では足りないページを、全文で読む<br>・記録した構造（材料や道具を使ったノート・ノートの手順・来歴）をたどる <Badge type="tip" text="v0.116.0 (2026-11-04) で追加" /><br>応答は少し遅くなり、AI の利用量も増えます。読むだけで、何も書き換えません。<br>オンのあいだは、チャットのモデルを選んでいればそのモデルで答えます。空欄なら、モデルの割り当ての高度な処理のモデルで答えます。[じっくり調べてから答えてもらう](/ja/ai-chat-and-ask#letting-the-ai-search-again)を参照。 |
| **音声ノート** | デスクトップ版だけ。モデルの割り当てとチャットの下にあり、モデルを登録する前から出ます。文字起こしがこのパソコンの中で動くためです。音声モデル・言語・よく使う用語・**録音中に文字起こしを進める**・**清書と要約に使う AI モデル** を設定します。[音声ノート](/ja/voice-notes#settings)を参照。 |
| **ナレッジ** | 取り込みと点検の設定です。次の 2 行が、その中身です。 |
| &nbsp;&nbsp;**資料の要約ページを作る** <Badge type="tip" text="v0.89.14 (2026-10-20) で追加" /> | 全員が既定オフです。オンにすると、PDF・URL の取り込みで、その資料の[要約](/ja/knowledge-layer)ページを 1 枚書きます。資料 1 件につき、AI の呼び出しが 1 回増えます。<br>要約は、トピックと同じ決まり（1 文ごとに出典）で書かれ、出典照合にかけられます。同じ資料を取り込み直すと、既存の要約を書き直します。ノートと Word には作りません。 |
| &nbsp;&nbsp;**自動点検を AI 解析（フル）にする** <Badge type="tip" text="v0.79.0 (2026-09-18) で追加" /> | 自動の点検を、機械判定だけのクイックから、AI 解析まで行うフルへ切り替えます。自動の点検は、取り込みの直後と、起動時（前回から 24 時間たっているとき）に走ります。既定はオフで、オンにした人だけ、自動の点検で AI を呼びます。<br>オンにしても、自動の点検が直すことはありません。直すのは、**おまかせで整える** を押したときか、自分で選んだときだけです。[ログと手入れ](/ja/knowledge-layer#ログと手入れ)を参照。 |
| **外部ツールとの接続（MCP）** | 最初から開いているグループで、**MCP サーバー** <Badge type="tip" text="v0.13.6 (2026-06-04) で追加" /> が入っています。外部のツールサーバーを、直接つなぎます。<br>つなぎ方は次のとおりです。確かめ済みの接続先（Tavily など）を選ぶか、公式の MCP Registry を探してキーを貼ります。**詳しい設定** では、サーバーの README から **JSON を貼る**、**手動入力** で 1 件ずつ設定する、**レジストリから** 候補を引く、のいずれかを選べます（[くわしく](/ja/ai-setup#mcp-サーバー)）。<br>畳んだ行には、登録しているサーバーの数が出ます。 |

## 照合データ

[世界照合](/ja/ai-grounding)が突き合わせる知識ベースを、ブラウザのように見て回るタブです。最初は空で、放っておいても自然に増えていきます。照合が知識ベースに当てはまらなかったとき、モデルの判定がここにキャッシュ（一時的な保存）されて、次から再利用されます。そのため、照合は使うほど速く、安くなります。

| グループ | 何ができるか |
|---|---|
| エントリ一覧 | 知識ベースのエントリを検索・絞り込みします。各エントリには、**seed** バッジ（手作業で整えて同梱したもの）か、**model** バッジ（モデルの判定をキャッシュしたもの）が付きます。 |
| 個別の削除 | キャッシュのエントリを 1 件ずつ削除します。seed のエントリは、画面からは削除できません。 |
| **沈殿エントリを一括削除** | モデルの判定から作られたキャッシュのエントリをまとめて消します。同梱の seed のエントリは残ります。 |

## ナレッジ管理 <Badge type="tip" text="v0.81.1 (2026-09-18) で追加" />

ナレッジの手入れをするタブです。編集できる**ナレッジスキーマ**は、このタブではなく、サイドバーの**スキル**一覧にあります。

ナレッジスキーマは、1 件だけの組み込み文書です。ナレッジの件数、検索、グラフには含まれません。

- 最初に作られるときだけ、そのときの画面の言語に合わせた既定の本文が保存されます。
- あとで画面の言語を変えても、本文が勝手に翻訳されたり置き換わったりすることはありません。
- 別の言語の同梱の既定本文に置き換えたいときは、ナレッジスキーマを開いて、確認つきの言語の切り替えを使います。
- 保存した規約は、これから作るトピック・問答（Q&A）・知見に適用されます。
- 編集、言語の切り替え、リセットをしても、既存のページが自動で作り直されることはありません。

以下は、[ナレッジ層](/ja/knowledge-layer)のメンテナンス作業です。どれも LLM を呼ぶので、各ジョブは実行前に確認を求めます。トークンのコストは、[使用量](#使用量)タブに記録されます。

| グループ | 何ができるか |
|---|---|
| **接続状態** | バックエンドの各部分の状態を表示します。デスクトップアプリでは、**バックエンドを再起動** ボタンも出ます。 |
| **全ナレッジの埋め込みを作り直す** | AI チャットの引用検索を支える埋め込みを作り直します。引用の検索が動かなくなったときに使います。<br>索引に、いま選んでいる埋め込みモデルのベクトルが残っているかも、軽く確認します（全件は調べません）。モデルが変わって作り直しが要りそうなときは、ここに 1 行の案内が出ます。費用が API キーにかかるため、自動では作り直しません。 |
| **トピックを整理** <Badge type="tip" text="v0.75.0 (2026-09-16) で追加" /> | 同じ概念を指す既存のトピックどうしを統合し、ページをまとめます。対象は、表記ゆれ、助詞の有無、細かすぎる事例単位のトピックなどです。<br>行うのはトピックページどうしの統合だけで、知見をトピックへ割り当てることはしません（2026-09-17 変更）。統合されたトピックは、完全には削除されず、ゴミ箱へ送られます。 |
| **トピックに種類を付ける** <Badge type="tip" text="v0.89.15 (2026-10-20) で追加" /> | [種類](/ja/knowledge-layer#topic-types)の無いトピックがあるときだけ出ます。<br>未分類のトピックについて、タイトルと定義の 1 文を 50 件ずつ AI に渡し、種類（概念・物質・材料・手法・装置・人・組織・場所）を書き戻します。呼び出し回数は、実行前に表示されます。本文は変えません。<br>種類は、ナレッジ一覧の種類列と、全体グラフの「トピック: …」の表示切替に使います。各トピックの種類は、ページのバナーで直せます。 |
| **ナレッジの一括再生成** | プロンプトやモデルを変えたあと、既存のナレッジページを作り直します。次のことができます。<br>・**対象の種類** のフィルタ（**トピック** / **知見** / **洞察**）。要約は、新規生成を停止済みのため対象外です。<br>・任意のモデルの指定<br>・キャンセル<br>・**失敗したナレッジだけ再試行**<br>トピックは資料から作り直すため、トピックを含む一括実行では、ページ数ではなく資料数のぶんだけ AI を呼びます。対象件数の横に AI の呼び出し回数を出し、トピックを含むときは実行前に確認します。 |
| **知見をまたぐ洞察を発見** | 知見を似たもの同士のグループ（クラスタ）に分けて順に調べ、知見の中にある関係の型を洞察として取り出します。同じ型の知見は、1 件の洞察にまとめます。<br>すべての知見が一度は調べられるまで繰り返します。必要な LLM の呼び出し回数は、手持ちの知見から計算して、実行前に表示されます。途中で止めることもできます。 |

![設定の Knowledge タブ。Connection Status、Discover Insights from Claims、Re-embed all Knowledge、Organize topics、Bulk regenerate Knowledge（対象の種類・モデル選択・Run bulk regenerate）のカードが縦に並んでいる。](/screenshots/settings-knowledge-tab.png)
