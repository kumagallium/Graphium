# デスクトップアプリ

デスクトップアプリは、Graphium の機能がすべて揃った形です。ノートはディスク上の実ファイルになります。AI バックエンドもアプリに同梱されています。共有やスマホからの受信など、デスクトップ限定の機能も使えます。

[kumagallium.github.io/Graphium/app/](https://kumagallium.github.io/Graphium/app/) のブラウザ版は、エディタを試すためのプレビューです。ノートはブラウザの IndexedDB に置かれるので、ブラウザ側の判断で消えることがあります。また、AI 機能に必要なバックエンドを、公開ページは持っていません。

## デスクトップアプリを使う理由

- **ノートが実ファイルになる。** ノートは 1 件ずつ、プレーンな JSON ファイルとして目に見えるフォルダに置かれます。バックアップも同期も自由にできます。ブラウザのデータベースの中に閉じ込められることはありません。
- **AI が同梱されている。** アプリが AI バックエンドを内蔵していて、自動で起動します。[モデルを登録](/ja/ai-setup)すれば、ナレッジ層・AI チャット・Composer がそのまま動きます。
- **共有できる。** チーム用フォルダへのノート公開はデスクトップ限定です。ブラウザはローカルフォルダを読み書きできないためです。[保存と同期](/ja/storage-and-sync)を参照してください。
- **スマホからの受信。** スマホで記録したものがデスクトップの受信箱に届きます。[スマホでの記録](/ja/mobile)を参照してください。
- **ネイティブメニューとショートカット。** OS 標準のメニューバーがあり、キーボードショートカットも確実に効きます。自動更新も付いています。

### ブラウザ版とデスクトップ版の比較

| | ブラウザ版プレビュー | デスクトップアプリ |
|---|---|---|
| ノートの保存場所 | ブラウザの IndexedDB（ブラウザ側で削除されることがある） | `Documents/Graphium` の中のプレーンな JSON ファイル |
| AI 機能 | 使えない（バックエンドがない） | 同梱。アプリと一緒に起動する |
| チームフォルダへの共有 | 使えない | 使える |
| スマホの記録の受信 | 使えない（送信はできる） | 使える |
| 更新 | ページを再読み込みすれば常に最新 | 起動時と 24 時間ごとに自動で確認 |

## ダウンロード

最新のインストーラは [Releases ページ](https://github.com/kumagallium/Graphium/releases/latest) から入手できます。

| プラットフォーム | ファイル | 自分のマシンを確かめる方法 |
|---|---|---|
| macOS（Apple Silicon: M1/M2/M3/M4） | `Graphium_x.x.x_aarch64.dmg` | アップルメニュー → このマックについて →「Apple M...」 |
| Windows（x64） | `Graphium_x.x.x_x64-setup.exe`（または `.msi`） | 設定 → システム → バージョン情報 → システムの種類が「x64 ベース」 |

Linux と Intel Mac 向けのビルドは、今のところ提供していません。それらのマシンでは[ブラウザ版](https://kumagallium.github.io/Graphium/app/)を使ってください。対応するプラットフォームを増やすことは、ロードマップに入っています。

### macOS にインストールする

1. ダウンロードした `.dmg` を開き、**Graphium** をアプリケーションフォルダにドラッグします。
2. アプリケーションフォルダから起動します。macOS 版はコード署名と公証を済ませているので、セキュリティの警告は出ずに開きます。
3. 初回起動時に、macOS が書類フォルダへのアクセス許可を求めることがあります。Graphium がそこにデータフォルダを作れるよう、許可してください。

### Windows にインストールする <Badge type="tip" text="v0.8.0 (2026-05-21) で追加" /> {#install-on-windows}

1. ダウンロードした `Graphium_x.x.x_x64-setup.exe` を実行します。
2. Windows 版はまだコード署名されていません。そのため、初回起動時に SmartScreen が「Windows によって PC が保護されました」と表示します。**詳細情報** → **実行** をクリックしてください。コード署名は、ロードマップに入っています。
3. あとはインストーラの指示に従います。

## 初回起動

初回起動時、Graphium は書類フォルダの中にデータフォルダを作ります（macOS は `~/Documents/Graphium`、Windows は `Documents\Graphium`）。中には、次のサブフォルダが並びます。どれも、そのまま開いて中を見られます。

| フォルダ | 中身 |
|---|---|
| `notes/` | ノート。1 件が 1 つの JSON ファイル |
| `media/` | 画像・PDF・音声・動画などの素材 |
| `wiki/` | ナレッジ層のページ（トピック・知見・洞察。以前に作られた要約が残っていればそれも含む） |
| `skills/` | 保存したスキルドキュメント |
| `appdata/` | ノートのインデックスなど、アプリの状態 |

データフォルダは、どこにでも移せます。Dropbox・Google Drive・OneDrive の同期フォルダに置けば、追加の設定なしで複数のマシンを同期できます。手順と、切り替える前の注意点は[保存先フォルダを変更する](/ja/storage-and-sync#changing-the-storage-folder)を参照してください。

## 更新する {#updating}

Graphium は、起動時と 24 時間ごとに更新を自動で確認します。新しいバージョンがあると、ウィンドウの上部にバナーが出ます（**Graphium x.x.x が利用可能です**）。

バナーには、**更新を確認** と **再起動して更新** が並びます。

- **更新を確認** は、もう一度確かめるボタンです。最新だと分かれば、バナーが消えます。
- **再起動して更新** を押すと、ダウンロード、インストール、アプリの再起動までまとめて行われます。
- ダウンロード中は、バナーに進捗が出ます。途中で失敗したときは、エラーがバナーに出るので、そのままもう一度試せます。

バナーは、確認した時点のバージョンを表示し続けます。そのあとさらに新しいリリースが出たときは、バナーの **更新を確認** を押すと、表示が最新のバージョンに変わります。

![更新バナー。Graphium 0.109.0 is available の文と、Check for updates・Restart to update の 2 つのボタン。](/screenshots/update-banner.png)

手動で確認することもできます。設定 → **アプリ情報** を開き、**更新を確認** を押します。

- 最新であれば、**最新版を使用しています** と表示されます。
- 新しいバージョンが見つかると、その場に **再起動して更新** ボタンが出ます。設定画面を離れずに、そのまま更新できます。動作はバナーと同じで、ダウンロードの進捗はボタンに、エラーはその下に表示されます。
- ブラウザ版では、**更新の確認はデスクトップ版でのみ利用できます** と表示されます。

自動での確認を止めたいときは、設定 → **アプリ情報** の **更新を自動で確認する** をオフにします。オフにすると、Graphium から更新サーバーへ自動では接続しなくなります。セキュリティ更新のお知らせも届かなくなるので、ときどき **更新を確認** で手動確認してください。

![アプリ情報タブにアプリのバージョンが表示され、デスクトップ版では更新セクションから手動で確認できる](/screenshots/settings-about-updates.png)

更新でノートに手が入ることはありません。データは `Documents/Graphium` にあり、アプリ本体とは分かれているためです。新しいバージョンで内部インデックスの形式が変わったときは、次の起動で Graphium がインデックスを自動で作り直します。各リリースの変更点は[リリース履歴](/ja/release-history)、またはメニューの **Help** → **Release Notes** で確認できます。

## メニューバー

デスクトップアプリには、OS 標準のメニューバーが付きます。メニューの項目名は、アプリの表示言語に関係なく、いつも英語です。

| メニュー | 項目 |
|---|---|
| **File** | **New Note** · **New Memo**（`⌘⇧M`）· **Print / PDF**（`⌘P`）· **Export PROV-JSON-LD** · Close Window |
| **Edit** | 標準の Undo / Redo / Cut / Copy / Paste / Select All |
| **View** | **Toggle Graph Panel** · **Toggle AI Chat** · **Zoom In**（`⌘=`）/ **Zoom Out**（`⌘-`）/ **Actual Size**（`⌘0`） |
| **Backend** | **Restart Backend**（アプリを再起動せずに、同梱の AI バックエンドだけを再起動する） |
| **Help** | **About Graphium** · **Release Notes** |

File メニューの **Export PROV-JSON-LD** は、開いているノートを書き出します。**計画の PROV を書き出す** は File メニューにはなく、計画ノートの **⋯** メニューにあります（計画ノートのときだけ出ます）。

## デスクトップ版のショートカット

デスクトップで覚えておくと便利なのは、次のものです（一覧は[キーボードショートカット](/ja/shortcuts)を参照）。

| ショートカット | 動作 |
|---|---|
| `⌘\`（Windows は `Ctrl+\`） | サイドバーを折り畳む / 元に戻す。すばやく集中モードに入れます。JIS キーボードでは `¥` キーでも動きます。 |
| `⌘⇧M`（`Ctrl+Shift+M`） | アプリのどこからでもクイックメモのダイアログを開きます。 |
| `⌘` `−`（Windows / Linux は `Ctrl` `−`） | 縮小。画面全体が小さくなり、一度に見渡せる範囲が広がります。 |
| `⌘` `+`（Windows / Linux は `Ctrl` `+`） | 拡大。 |
| `⌘` `0`（Windows / Linux は `Ctrl` `0`） | 100% に戻します。 |
| `Ctrl` + マウスホイール（Windows / Linux） | 拡大・縮小します。上に回すと拡大です。 |

デスクトップアプリでは、`⌘⇧M` が File メニューの **New Memo** としても登録されています。そのため、エディタがキー入力を受け取ってしまう場面でも確実に動きます。メニューバーから、この機能を見つけることもできます。

<Badge type="tip" text="v0.84.0 (2026-09-30) で追加" /> 拡大・縮小のキーは、同時に押します（`−` はマイナスのキー、`+` はプラスのキーです）。倍率は 50% から 150% まで、段階的に変わります。サイドバーやパネルも含めて、画面全体が一緒に変わります。ウィンドウが狭いときは、画面の構成が切り替わらないように、上の段は使えません。

- 倍率は、アプリを閉じても覚えています。
- 設定 → **表示・言語** → **画面の大きさ** からも選べます。
- JIS 配列では、`+` キー（Shift なしなら `;`）で拡大できます。

画面が狭く感じるときは、90% に縮小してみてください。Windows のノート PC は、表示スケールの既定が 150% なので、見える範囲が思ったより狭くなります。

::: tip
ノートや引用の中の外部リンクは、アプリのウィンドウ内ではなく OS の既定ブラウザで開きます。
:::

## トラブルシューティング

### 更新のダウンロードに失敗する

バナーや設定 → **アプリ情報** に、更新を取得できなかったと表示されるときは、ダウンロードが最後まで届かずに途切れています。回線が遅い、社内プロキシを経由している、セキュリティソフトが通信を検査している、といった事情が多いです。

- Graphium は、自動で 1 回だけ取り直します。
- それでも失敗したときは、少し時間をおいて **更新を確認** をもう一度押してください。
- 繰り返し失敗するときは、エラーの横に出る **手動でダウンロード** から、リリースページのインストーラを取得します。今のアプリに上書きインストールできます。`Documents/Graphium` のノートはそのまま残ります。

**詳細を表示**（設定では **エラーの詳細**）には、updater が返した元のメッセージと、途切れるまでに何 MB 届いたかが残ります。問い合わせるときに添えると、原因が早く分かります。

### 更新直後に AI 機能が失敗する

自動更新の直後に、AI の接続先がエラー（404 など）を返し始めることがあります。前のバージョンの補助プロセスが、残っている可能性があります。Graphium を完全に終了して（macOS は `⌘Q`、Windows はウィンドウを閉じる）、もう一度起動してください。それでも AI が応答しないときは、メニューバーの **Backend** → **Restart Backend** を試します。

### 初回起動で「Windows によって PC が保護されました」と出る

Windows 版は署名されていないので、この表示は想定どおりです。**詳細情報** → **実行** をクリックしてください（[Windows にインストールする](#install-on-windows)を参照）。

### 起動時にノートフォルダを読み込めない

ノートフォルダを開けなかったという画面で止まったときは、**詳細を表示** を押してください。実際に何が原因で失敗したかが出るので、それに応じて対処します。

- **macOS がアクセスを保留している。** 更新の直後に出ることがほとんどです。差し替わったアプリが、更新前のアプリの権限を引きずったまま起動してしまうためで、起動し直せば通ります。画面の **アプリを再起動** を押すか、Graphium を完全に終了して（`⌘Q`）開き直してください。同じ画面が戻ってくるときは、システム設定 → プライバシーとセキュリティ → ファイルとフォルダ を開き、Graphium の「書類」フォルダをオンにします。そのあと **再読み込み** を押します。
- **時間がかかっている。** フォルダの応答が間に合わなかった状態です。**再読み込み** を押すと、たいてい 2 回目で通ります。
- **フォルダが見つからない。** 設定 → **ストレージ** で、外付けドライブや同期フォルダに保存先を移している場合は、それが使える状態か確認してください。

### macOS でデータフォルダに書き込めない

Graphium が保存できないと表示する場合は、システム設定 → プライバシーとセキュリティ → ファイルとフォルダを開き、Graphium に書類フォルダへのアクセス権があるか確認してください。または設定 → **ストレージ** から、書き込める場所に保存先を移します。
