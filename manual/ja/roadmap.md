# 機能ロードマップ

Graphium は 2026 年 3 月から小さなリリースを重ねてきました。このページはその振り返りです。「できること」が変わった節目だけを時系列で並べ、マニュアルの該当ページへリンクしています。全リリースの全変更は[リリース履歴](/ja/release-history)にあります。

::: tip バージョン表記の読み方
各機能ページには、その機能が初めて入ったバージョンのバッジ（例: <Badge type="tip" text="v0.18.0 (2026-07-15) で追加" />）が該当セクションに付いています。お使いのアプリがバッジより古い場合は、[更新](/ja/desktop-app#updating)すると使えるようになります。
:::

## これから

Graphium は個人のオープンソースプロジェクトなので、この先は日程ではなく方向です。いま考えている筋は 3 つあります。

- **概念を増やさず、減らす。** 上のリリース群から繰り返し学んだのは、機能を足すより隠れた閾値を取り除いたほうが効くということです。新機能と並行して、単純化も続けます。
- **育っても信頼できるナレッジ。** 生成されたナレッジの来歴をより深く辿れるようにし、世界照合は使うほど安くなる方向へ。
- **対応環境を広げる。** 現在検証済みのデスクトップビルドは macOS（Apple Silicon）と Windows x64 です。他の環境は未検証です。

実際に進行中のものは、GitHub の[リリース](https://github.com/kumagallium/Graphium/releases)と[イシュー](https://github.com/kumagallium/Graphium/issues)をご覧ください。
