# キーボードショートカット

Graphium は、ショートカットの数をあえて少なくしています。記録・保存・ラベル付けのための、わずかなキーだけです。書いている間ずっと、手をキーボードに置いたままでいられます。

このページでは、すべてのショートカットと、それぞれが使える場面をまとめます。アプリの中でショートカットを思い出せる場所も紹介します。

表記について: `⌘` は mac の Command キー、`⇧` は Shift、`⌥` は Option です。Windows と Linux では、`⌘` が `Ctrl`、`⌥` が `Alt` になります。以下のショートカットは、どちらの形も併記しています。

## 一般

| mac | Windows / Linux | 動作 |
|---|---|---|
| `⌘K` | `Ctrl+K` | Composer を開きます。ノートを探すことと AI に聞くことを、1 つの入力欄で行えます。どの画面からでも開きます。ノートを編集していないときや、[設定](/ja/settings)に AI モデルを登録していないときは、検索だけの表示になります。左のナビの **検索** ボタンでも、同じ画面が開きます。[チャットと Ask](/ja/ai-chat-and-ask)を参照してください。 |
| `⇧Enter` | `Shift+Enter` | <Badge type="tip" text="v0.102.0 (2026-10-29) で追加" /> ノートを編集中に Composer で押すと、ハイライトされたノートを全画面で開きます（素材は素材ギャラリーで開きます）。ふつうの `Enter` なら、編集中のノートの横にあるサイドピークで開きます。このとき、2 つのノートはリンクされません。[チャットと Ask](/ja/ai-chat-and-ask#finding-notes)を参照してください。 |
| `⌘⇧M` | `Ctrl+Shift+M` | アプリのどこからでも、クイックメモのダイアログを開きます。ノートエディタでも、ノート一覧でも、どの画面でも使えます。メモは、今すぐ記録しておき、あとでノートの材料に使うものです。 |
| `⌘P` | `Ctrl+P` | <Badge type="tip" text="v0.108.8 (2026-10-30) で追加" /> 開いているノートを印刷します。ノートの `⋯` メニューの **印刷・PDF** と同じです。画面全体ではなく、タイトル・ラベル・来歴グラフを含むノートが印刷されます。システムの印刷ダイアログから、PDF として保存できます。ノートを開いていないときは、ブラウザ自身の印刷がふだんどおり動きます。 |
| `⌘D` | `Ctrl+D` | カーソルのあるブロックを、そのすぐ下に複製します。エディタの中でだけ効きます。[ブロックを複製する](/ja/notes-and-editor#duplicating-a-block)を参照してください。 |
| `⌘F` | `Ctrl+F` | **ノート内を検索** を開き、現在のノートの中を検索して、一致箇所をハイライトします。ポインタが PDF ビューアの上にあるときは、代わりに [PDF の中を検索](/ja/materials-and-citations#finding-text-in-a-pdf) が開きます。一覧の画面（ノート・素材・ナレッジ・ラベル・工程・スキル・全体グラフ）では、その画面の検索欄にカーソルが入ります。すでに入っている語は選択された状態になるので、そのまま打ち替えられます。どれにも当てはまらないときは、ブラウザ自身の検索がふだんどおり動きます。 |
| `⌘\` | `Ctrl+\` | サイドバーを折り畳む / 開いて、書くことに集中できるようにします。デスクトップサイズの画面でだけ使えます。小さい画面には、折り畳める常設のサイドバーがないためです。JIS キーボードでは `¥` キーでも動きます。 |
| `Esc` | `Esc` | Composer、ノート内の検索バー、クイックメモのダイアログ、そのほかほとんどのダイアログを閉じます。 |

## 保存

| mac | Windows / Linux | 動作 |
|---|---|---|
| `⌘S` | `Ctrl+S` | 現在のノートをすぐに保存します。Graphium は自動保存もしているので、これは席を離れる前に念のため押すためのものです。メインのエディタとサイドピークの、どちらでも動きます。 |
| `⌘⇧S` | `Ctrl+Shift+S` | 今の状態を履歴に残します。名前を付けられるスナップショットで、**履歴** パネルから見返し・比較・複製ができます。 |
| `⌘⌥S` | `Ctrl+Alt+S` | 上と同じです。OS・ブラウザ・拡張機能が `⌘⇧S` を予約していて、キー入力が Graphium に届かないときの代わりに使います。 |

履歴に残せるのは、自分のノートです。AI が生成したナレッジのページは、スナップショットを取りません。環境の都合でどちらのショートカットも効かないときは、ノートの `⋯` メニューの **今の状態を履歴に残す** で、同じことができます。

## ラベル

次の 4 つは、選択したテキストにインラインのラベルを付けます。使えるのは、ステップブロックの本文の中です。ステップブロックは、ノートのうち[来歴グラフ](/ja/labels-and-provenance)のステップになる部分です。すでにラベルの付いたテキストで同じショートカットを押すと、ラベルが外れます。

| mac | Windows / Linux | ラベル |
|---|---|---|
| `⌘⇧I` | `Ctrl+Shift+I` | **インプット**（そのステップが使う素材や材料） |
| `⌘⇧E` | `Ctrl+Shift+E` | **ツール**（使った装置やソフトウェア。*Equipment* の *E* です。`⌘⇧T` は、ブラウザが閉じたタブを開き直すために予約しています） |
| `⌘⇧P` | `Ctrl+Shift+P` | **パラメータ**（設定や条件） |
| `⌘⇧O` | `Ctrl+Shift+O` | **アウトプット**（そのステップが生み出すもの） |

使えない場所がいくつかありますが、どれも意図したものです。

- ラベルを*付けられる*のは、ステップの本文の中だけです。ステップのタイトルは活動そのものの名前なので、付けられません。表のセルの中も、表が構造として解釈されるので付けられません。すでに付いているラベルを*外す*ことは、どこでもできます。
- テキストを選択すると、同じ 4 つのボタンがフローティングツールバーに出ます。ショートカットを使わなくても構いません。

## 文字の色 {#text-color}

| mac | Windows / Linux | 動作 |
|---|---|---|
| `⌘⇧H` | `Ctrl+Shift+H` | 選択したテキストに、直前に使った色をもう一度付けます。文字色でも背景色でも、最後に選んだ方が付きます。すでに同じ色が付いていれば、外れます。 |

色を選ぶには、テキストを選択したときに出るツールバーの**色**ボタンを使います。そこで選んだ色が、以後このショートカットで付く色になります。まだ一度も色を選んでいなければ、黄色の背景（蛍光ペン）が付きます。覚えた色はこの端末に残り、ノートには書き込まれません。

## 確定

| mac | Windows / Linux | 動作 |
|---|---|---|
| `⌘Enter` | `Ctrl+Enter` | ふつうの `Enter` が改行になる複数行の入力欄で、送信・確定します。AI チャット、Composer、引用のピッカー、クイックメモのダイアログ、[設定](/ja/settings)のフォーム（MCP サーバーの追加など）が対象です。 |

## ノート一覧 <Badge type="tip" text="v0.83.6 (2026-09-29) で追加" /> {#notes-list}

[すべてのノート](/ja/notes-and-editor#the-notes-list)で行をクリックしてサイドピークを開いたあと、続けて次のキーが使えます。

| mac | Windows / Linux | 動作 |
|---|---|---|
| `↓` / `↑` | `↓` / `↑` | ピークを次・前の行のノートに切り替えます。押し続けると、指を離したところのノートを開きます。 |
| `Enter` | `Enter` | ピークで開いている行のノートを全画面で開きます（行のダブルクリックと同じ）。 |

これらのキーが効くのは、一覧を操作しているときだけです。ピークの本文や検索欄に書いている間は、ふだんどおりカーソルが動きます。一覧の行をもう一度クリックすると、一覧の操作に戻ります。

## 入力で開くメニュー

2 つの文字は、書いている途中で入力すると、メニューを開きます。修飾キーを使うショートカットではありませんが、同じように指で覚えておくと便利です。

| 入力 | 場所 | 動作 |
|---|---|---|
| `/` | 空行で | スラッシュメニューを開きます。ブロック（ステップ・表・数式・コールアウトなど）、メディア、引用、テンプレートを入れられます。[ノートとエディタ](/ja/notes-and-editor)を参照してください。 |
| `@` | 文中のどこでも | 他のノート・素材・ナレッジのページをリンクする検索メニューを開きます。その場で新しいノートを作ることもできます。 |

空のノートには、この 3 つの入口を示す小さなガイドカードが出ます。**AI に頼む**（`⌘K`）、**ノートを繋ぐ**（`@`）、**スラッシュメニュー**（`/`）です。最初のノートが、基本を教えてくれます。

## 知っておくと便利なこと

**ラベルのショートカットは、文字ではなくキーの位置で判定します。** `⌘⇧I` などは、物理的なキーの位置で検出します。そのため、US・JIS そのほかどの配列でも、同じように動きます。そのキーにどの文字が印字されているかは、関係ありません。

**新規ノートのショートカットは、あえて用意していません。** `⌘⇧N` は、ブラウザが新しいプライベートウィンドウのために予約しているので、確実に上書きできません。ショートカットを置くと、一部の利用者で意図しない動きをします。代わりに、サイドバーの **+ ノート** ボタンを使ってください。メモにはショートカットがあり、ノートにはない、という違いも意図したものです。メモは、すぐに記録するためのものです。ノートは、腰を据えて書く場所です。

**アプリの中でも、ショートカットを思い出せます。** このページを暗記する必要はありません。ショートカットは、使う場所に表示されています。以下は mac での見え方です。Windows と Linux では、`⌘` の代わりに `Ctrl` と表示されます（例: **メモをすばやく書き留める（Ctrl+Shift+M）**）。

- フローティングツールバーのラベルボタンには、キーキャップの表示（`⌘` `⇧` `I`）とツールチップが付きます。
- サイドバーの **素材** タブで **メモ** の横にある **+** のツールチップは **メモをすばやく書き留める（⌘+⇧+M）**、サイドバーの開閉ボタンは **サイドバーを折り畳む（⌘+\\ / ⌘+¥）** です。
- ノートの `⋯` メニューでは、**保存**・**今の状態を履歴に残す**・**印刷・PDF** の右端にショートカットが表示されます。
- Composer のフッターには `⌘Enter` **で送信** と `Esc` **で閉じる** が出ます。クイックメモのダイアログには **⌘+Enter で保存** と書かれています。
