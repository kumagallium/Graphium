Privacy Policy — Graphium Web Clip

Last updated: 2026-11-04

日本語

Graphium Web Clip is a Chrome extension that sends text you select in Chrome, or the page you are on, to the Graphium app running on your own computer. This policy covers the extension only. For the Graphium app, see the Graphium privacy policy.

Summary

  • The extension sends data only to http://127.0.0.1 — the Graphium app on the same computer. It never sends anything to the developer or to any other server.
  • It reads a page only when you clip it (the toolbar icon, the keyboard shortcut, or the right-click menu).
  • No analytics, no tracking, no advertising, no remote code. Data is never sold or shared.

What the extension handles

DataWhenWhere it goes
The text you selectedOnly when you clipGraphium on this computer (127.0.0.1)
The page's URL and title, and a DOI if the page declares one in its metadataOnly when you clipGraphium on this computer
The time of the clipOnly when you clipGraphium on this computer
The pairing code (the local port and a random token)When you connect the extension to GraphiumChrome's extension storage (chrome.storage.local) on this computer
Clips that could not be sent yet (at most 200)When Graphium is not runningChrome's extension storage on this computer, until they are sent

The extension does not read your browsing history, other tabs, form fields, passwords or cookies. It has no access to pages until you clip one.

Permissions

PermissionWhy
activeTab, scriptingRead the selection, title, URL and metadata of the current tab at the moment you clip it.
contextMenusAdd “Clip to Graphium” to the right-click menu.
storageKeep the pairing code and the clips waiting to be sent.
http://127.0.0.1/*Send clips to the Graphium app on this computer.

Removing your data

Removing the extension deletes the pairing code and any unsent clips. Clips that already reached Graphium are ordinary memos and notes in Graphium, stored where Graphium stores your notes; delete them there. To disconnect without removing the extension, regenerate the pairing code in Graphium (Settings → Storage → Send from your phone or browser → Web clip).

Changes

Changes to this policy are posted on this page and reflected in the “Last updated” date.

Contact

Please open an issue on the GitHub repository. The extension's source code is in extensions/chrome.

プライバシーポリシー — Graphium Web クリップ

最終更新日: 2026-11-04

Graphium Web クリップは、Chrome で選んだ文や開いているページを、あなたのコンピューターで動いている Graphium に送る Chrome 拡張機能です。このポリシーは拡張機能だけを対象にしています。Graphium 本体については Graphium のプライバシーポリシーをご覧ください。

要点

  • 拡張機能がデータを送るのは http://127.0.0.1（同じコンピューターの Graphium）だけです。開発者やほかのサーバーには何も送りません。
  • ページを読むのは、あなたがクリップしたとき（ツールバーのアイコン、キーボードショートカット、右クリックメニュー）だけです。
  • アクセス解析・トラッキング・広告・リモートコードはありません。データを売ったり第三者に渡したりしません。

扱うデータ

データいつ送り先・置き場所
選んだ文クリップしたときだけこのコンピューターの Graphium（127.0.0.1）
ページの URL と題（メタデータに DOI があれば DOI も）クリップしたときだけこのコンピューターの Graphium
クリップした時刻クリップしたときだけこのコンピューターの Graphium
ペアリングコード（ポート番号とランダムな合言葉）拡張機能を Graphium とつないだときこのコンピューターの Chrome の拡張機能用ストレージ（chrome.storage.local）
まだ送れていないクリップ（最大 200 件）Graphium が起動していないときこのコンピューターの Chrome の拡張機能用ストレージ（送れたら消えます）

閲覧履歴、ほかのタブ、フォームの入力、パスワード、Cookie は読みません。クリップするまで、ページには一切アクセスしません。

権限理由

データを消すには

拡張機能を削除すると、ペアリングコードと送れていないクリップも消えます。Graphium に届いたクリップは Graphium の通常のメモとノートになり、Graphium のノートの保存先に置かれます。消すときは Graphium で消してください。拡張機能を残したまま接続だけ切るときは、Graphium の「設定 → ストレージ → スマホやブラウザから送る → Web クリップ」でコードを作り直します。
